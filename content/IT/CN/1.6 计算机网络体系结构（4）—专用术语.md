## 1. 📊 计算机网络体系结构专用术语总结
> [!summary] 本节核心内容
> 本节系统介绍了计算机网络体系结构中的**三大核心术语**：**实体**、**协议**、**服务**，以及相关的**协议三要素**（语法、语义、同步）、**服务访问点**、**协议数据单元（PDU）** 和**服务数据单元（SDU）**。这些术语是理解分层通信模型的基础。

### 1.1. 📋 三大核心术语对比表

| 术语 | 定义 | 特点 | 关系 |
|-----|------|------|------|
| **实体** | 任何可发送或接收信息的**硬件或软件进程** | - 存在于每一层<br>- 是协议的实现者和服务的使用者 | 通信双方相同层的实体构成**对等实体** |
| **协议** | 控制两个对等实体进行**逻辑通信**的规则的集合 | - **水平的**（对等实体间）<br>- 包含三要素：语法、语义、同步 | 控制对等实体的逻辑通信，提供**服务**的基础 |
| **服务** | 下层实体为上层实体提供的**通信能力** | - **垂直的**（相邻层间）<br>- 上层只使用，不关心实现细节（透明） | 通过协议实现，通过**服务访问点**提供 |

## 2. 🎯 实体（Entity）详解
> [!info] 实体的定义与特点
> - **定义**：任何可==发送或接收==信息的==硬件==或软件==进程==
> - **示例**：
>   - **物理实体**：==网卡==、路由器==接口==
>   - **软件实体**：应用程序==进程==、TCP/IP==协议栈==
> - **对等实体**：通信双方**相同层次**中的实体
>   - 例如：主机A的应用层实体 ↔ Web服务器的应用层实体

**对等实体示例**：
```
主机A                         Web服务器
┌─────────────┐               ┌─────────┐
│ 应用层实体E │ ← 对等实体 → │ 应用层实体F  │
│ 运输层实体D │ ← 对等实体 → │ 运输层实体G  │
│ 网络层实体C │ ← 对等实体 → │ 网络层实体H  │
│ 数据链路层B │ ← 对等实体 → │ 数据链路层I  │
│ 物理层实体A │ ← 对等实体 → │ 物理层实体J  │
└─────────────┘               └─────────┘
```

## 3. 🔑 协议（Protocol）详解
> [!important] 协议的核心概念
> - **定义**：控制两个对等实体进行**逻辑通信**的规则的集合
> - **逻辑通信**：假想出来的通信，方便单独研究某一层而不考虑其他层
> - **重要性**：网络协议是计算机网络正常运行的基础

### 3.1. 协议三要素

| 要素     | 定义                 | 示例                      | 作用       |
| ------ | ------------------ | ----------------------- | -------- |
| **语法** | 定义通信双方所交换信息的**格式** | IP数据报格式：字段长度、顺序         | 规定信息如何组织 |
| **语义** | 定义通信双方所要完成的**操作**  | HTTP GET请求：服务器查找内容并返回   | 规定信息做什么  |
| **同步** | 定义通信双方的**时序关系**    | TCP三次握手：SYN→SYN-ACK→ACK | 规定信息何时发送 |

> [!example] 协议三要素实例
> **以HTTP协议为例**：
> 1. **语法**：HTTP报文格式（请求行、首部字段、主体）
> 2. **语义**：GET表示获取资源，POST表示提交数据
> 3. **同步**：先建立TCP连接，再发送HTTP请求


## 4. 🔄 服务（Service）详解
> [!check] 服务的核心特点
> - **定义**：下层实体为上层实体提供的通信能力
> - **特点**：
>   - **垂直方向**：下层 → 上层
>   - **透明性**：上层只需使用服务，无需知道实现细节
>   - **通过协议实现**：服务需要协议支持才能提供
> - **类比**：手机用户享受通话服务，无需了解手机内部原理

**服务与协议的关系**：
```
应用层实体 ← 服务 ← 运输层协议（TCP/UDP） ← 对等逻辑通信 ← 运输层协议
（使用服务）      （实现服务）                    （水平协议）      （实现服务）
                 ↑                            ↑
              服务访问点                    逻辑通信
```

## 5. 📍 服务访问点（SAP）
> [!tip] 服务访问点定义与作用
> - **定义**：在同一系统中，相邻两层的实体交换信息的**逻辑接口**
> - **作用**：区分不同的服务类型，为上层提供访问下层的入口
> - **各层示例**：

| 层次 | 服务访问点（SAP） | 示例字段 |
|------|------------------|----------|
| **数据链路层** | 帧的类型字段 | 以太网帧的"Type"字段 |
| **网络层** | IP首部的协议字段 | 标识是TCP(6)还是UDP(17) |
| **运输层** | 端口号 | HTTP(80)、HTTPS(443) |

## 6. 📦 数据单元术语对比

| 术语 | 英文缩写 | 定义 | 数据单元示例 |
|------|----------|------|-------------|
| **协议数据单元** | **PDU** | 对等层次之间传送的数据包 | - 物理层：比特流<br>- 数据链路层：帧<br>- 网络层：分组/IP数据报<br>- 运输层：TCP报文段/UDP用户数据报<br>- 应用层：应用报文 |
| **服务数据单元** | **SDU** | 同一系统内层与层之间交换的数据包 | 上层交给本层要发送的数据 |
| **关系** | - | 多个SDU可以合成为一个PDU<br>一个SDU也可以划分为几个PDU | 封装与解封装过程 |

## 7. 🎓 分层通信模型图解
```
层次模型：                   数据传输关系：
┌─────────────────┐              ┌─────────────────┐
│   上层实体      │ ← 服务  ← │     服务原语     │
├─────────────────┤              ├─────────────────┤
│   本层实体      │              │   PDU (n)       │  ← 协议控制
├─────────────────┤              ├─────────────────┤
│   下层实体      │ ← 服务  → │     服务原语     │
└─────────────────┘              └─────────────────┘
              ↓                          ↓
         SDU(n-1)                PDU封装与传输
```

## 8. 🔑 关键概念辨析表

| 对比维度 | 协议 | 服务 |
|----------|------|------|
| **方向** | 水平（对等实体间） | 垂直（相邻层间） |
| **关系** | 控制逻辑通信的规则 | 通过协议提供的功能 |
| **可见性** | 对上层透明 | 上层可以直接使用 |
| **交互对象** | 对等实体间 | 上下层实体间 |
| **关注点** | 如何通信 | 提供什么功能 |

## 9. 💡 学习要点总结

> [!success] 必须掌握的核心理念
> 1. **实体→对等实体**：任何层的通信都是实体间通信，相同层实体构成对等实体
> 2. **协议三要素**：语法（格式）、语义（操作）、同步（时序）缺一不可
> 3. **服务与协议关系**：
>    - 协议是**水平**的，服务是**垂直**的
>    - 协议是服务的**实现手段**，服务是协议的**表现形式**
> 4. **透明性原则**：上层只需使用下层服务，无需了解其实现（协议）

> [!note] 协议的重要特性
> 1. **逻辑通信**：便于分层研究和独立设计
> 2. **标准化**：语法、语义、同步都需要明确定义
> 3. **层次化**：每层都有自己的协议
> 4. **对等性**：相同层协议在通信双方是相同的


## 10. 📝 术语间关系记忆图
```
实体（每层都有，实现通信）
  │
  ├─→ 对等实体（同层间）
  │      │
  │      └─→ 协议（控制逻辑通信）
  │             ├─→ 语法（格式）
  │             ├─→ 语义（操作）
  │             └─→ 同步（时序）
  │
  └─→ 服务（层间提供）
         │
         ├─→ 服务访问点（SAP，接口）
         │
         ├─→ 服务原语（命令）
         │
         ├─→ 服务数据单元（SDU，层间数据）
         │
         └─→ 协议数据单元（PDU，对等层数据）
```
