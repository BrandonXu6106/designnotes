- PS中3D效果的特点与局限性
	- Photoshop的3D功能效果有限，其核心优势在于特效制作、色彩处理、明暗调整及设计思维应用。三维设计主要依赖参数调整而非创意逻辑，PS的3D模块仅适用于简单场景构建，复杂商业设计需使用专业三维软件。


- 专用三维软件的优势﻿
	- 专业三维软件如3ds Max和Cinema 4D在建模精度与渲染质量上显著优于Photoshop，适用于商业级三维设计需求。


- PS的特长与设计思维
	- Photoshop的核心竞争力体现在平面设计逻辑、色彩管理及创意表达，而非参数化三维建模。


- 三维效果的参数性与局限性
	- 三维建模依赖技术参数输入
	- 但PS存在以下局限：
		- 渲染耗时长 
		- 仅支持简单结构建模
		- 复杂场景易导致软件崩溃
		- 高级功能（如3D打印、网格处理）实操性低


- 电脑配置对3D设计的影响﻿
	- 低配置电脑运行3D功能时需注意：
		- 控制文件尺寸
		- 简化模型结构
		- 避免多对象复杂场景


- 3D功能的学习建议
	- 该模块为选修内容，不影响PS核心功能学习，可根据兴趣选择是否深入。


## 1. 从文件新建3D图层
操作流程：
- 点击"从文件新建3D图层"
- 仅支持.dae等专业三维格式 
- JPG/PSD等平面格式无法识别


### 1.1. 3D文件格式的识别与打开﻿
格式兼容性对比：

| 文件类型 | 是否支持 | 备注            |
| ---- | ---- | ------------- |
| .jpg | ×    | 平面图像格式        |
| .psd | ×    | Photoshop工程文件 |
| .dae | √    | 三维数据交换标准格式    |

### 1.2. 3D对象的渲染与图层处理﻿
导入后的操作选项：
- 右键菜单提供渲染/栅格化功能
- 直接双击打开会生成无背景新文档
- 需通过3D菜单导入才能合并到现有文件


### 1.3. 3D文件的保存与导出
导出流程：
- 创建3D对象（如汽水瓶模型）
- 执行"导出3D图层"命令
- 保存为.dae格式文件


### 1.4. 例题2:3D对象的创建与调整﻿
模型调整要点：
- 通过属性面板修改材质类型（如金属质感）
- 支持光源角度调整
- 系统预设模型可快速生成基础造型


## 2. 合并3D图层﻿
合并条件与效果：
- 需至少两个3D图层
- 合并后保持独立变换属性
- 需手动统一不同对象的尺寸比例


## 3. 3.球面全景图﻿
### 3.1. 球面全景图的概念与操作﻿
球面全景图可通过多图拼合实现360°场景再现，需配合"Photomerge"功能使用。

### 3.2. 自动拼合命令的使用﻿
Photomerge操作规范：
- 选择有重叠区域的连续照片
- 系统自动对齐并生成透明像素
- 需手动裁剪消除边缘透明区域


### 3.3. 全景图图层的创建与合并﻿
全景图转换流程：
- 拼合后的图像需合并图层
- 执行"球面全景"命令
- 生成可交互的三维空间视图 - 支持街景地图式多角度查看


### 3.4. 全景图的价值与实际应用﻿
全景图功能在平面设计领域商业价值较低，主要用于提供沉浸式观看体验。该功能将多张图片拼接成球体效果，用户可站在球心位置环视四周。画面衔接处可能出现明显缝隙，需通过PS手动修补以实现自然过渡。由于应用场景有限且客户接受度低，该功能仅作为辅助工具了解即可。

### 3.5. 全景图导出与保存﻿
拼接完成的全景图可导出为JPG格式图片。PSD文件可保留3D观看功能，通过文件菜单存储后仍可反复调整视角。实际工作中该功能使用频率极低，因客户需依赖PS软件查看，操作流程繁琐且缺乏商业变现途径。

## 4. 所选图层新建3D模型

- 文字/色块图层均可转换为3D模型：通过"从所选图层新建3D模型"命令实现
- 基础操作要点：生成的3D效果可通过撤销命令或删除图层还原
- 后续调整需配合3D工具：模型尺寸、变形等高级操作需在下节课详解


## 5. 所选路径新建3D模型﻿

- 路径转换原理：使用多边形工具创建路径后，执行"从所选路径新建3D模型"命令
- 生成效果特征：路径自动转化为具有立体感的几何形体
- 操作限制：空路径仍可执行转换，与选区新建存在差异


## 6. 所选选区新建3D模型

| 操作条件  | 执行结果          | 特殊说明           |
| ----- | ------------- | -------------- |
| 空白选区  | 系统提示"不能完成命令"  | 需图层包含像素或填充色块   |
| 含内容选区 | 生成基于选区内容的3D模型 | 模型效果取决于底层图像/颜色 |

## 7. 映射
映射功能通过系统预设将2D图层转化为3D效果。明信片模式可将图像模拟为立体卡片，产生透视变形效果。操作要点包括：
- 图层需包含可视元素：空白图层无法触发映射功能
- 控件交互：通过黄色方框调整模型角度与尺寸
- 实际应用局限：该功能多用于透视参考，商业设计场景使用价值较低


## 8. 应用案例﻿
### 8.1. 例题:帽子渲染
通过"网格预设"功能可将图片纹理映射至3D帽子模型。系统自动匹配贴图位置，生成可旋转角度的三维对象。渲染耗时与硬件性能直接相关，未渲染的模型表面质感较差。

### 8.2. 例题:酒瓶渲染
酒瓶预设模型自动识别标签区域完成纹理贴合。专业级渲染需耗时20分钟至1小时，输出效果仍无法与专业3D软件媲美。操作时需注意图像尺寸控制，过大文件会导致性能严重下降。

### 8.3. 例题:球体渲染﻿
- 球体渲染操作步骤：选择3D网格预设中的球体，系统自动生成球体模型。
- 贴图应用：点击汽水贴图可将图像自动贴合至球体表面，贴图与物体结合需通过系统自带功能实现。
- 材质调整：材质标签支持更换（如铝制盖改为金盖），光源方向可自定义以优化渲染效果。
- 渲染注意事项：
    - 模型底色建议使用亮灰色，避免暗色影响后期打光效果。
    - 渲染完成后禁止移动模型角度，否则会恢复至未渲染状态。
    - 栅格化3D为最终步骤，需右击选择对应选项以固定渲染结果。


### 8.4. 例题:易拉罐渲染﻿
- 易拉罐渲染流程：生成3D模型后自动转为独立图层，支持任意角度调整。
- 基础模型扩展：立方体、圆柱体等操作逻辑相同，旋转功能需后期学习掌握。
- 贴图映射实验：导入彩色图片后执行深度映射命令，明暗对比强烈的图像可生成山峰状立体效果。


### 8.5. 例题:深度映射到平面

| 映射类型   | 效果特征       | 应用场景          |
| ------ | ---------- | ------------- |
| 平面     | 单层明暗起伏，无厚度 | 快速生成浮雕状纹理     |
| 双面平面   | 对称复制单层结构   | 需要正反视角展示的简易模型 |
| 纯色突出   | 根据明暗自动生成厚度 | 立体文字或阶梯状物体制作  |
| 双面纯色突出 | 对称结构且填充厚度  | 完整立体模型（如包装盒）  |

- 核心原理：
    - 亮色区域突出更多，暗色区域凹陷，纯黑色不产生突出效果。
    - 彩色图像需具备明暗对比，单色无法生成层次感。
- 操作验证：
    - 阶梯式灰度填充验证明暗与突出高度的正相关关系。
    - 文字叠加不同明度背景后映射，仅多色混合图层能产生立体台阶效果。
- 渲染限制：平面映射类操作均无真实厚度，需通过纯色突出命令补充。


### 8.6. 例题:单色映射圆柱体
- 新建图层并填充蓝灰色，执行单色映射后生成圆柱体造型。单色映射产生的圆柱体结构简单，无需过多讲解。
- 通过Ctrl+T调整图层形状后复制多层，分别使用Ctrl+U调整明度：顶层最暗，中层适中，底层最亮。合并图层后执行3D圆柱体映射，生成的圆柱体呈现顶部细窄、底部粗壮的渐变效果。
- 明暗对比原理：亮度越高凸起越明显，暗度越高凹陷越显著。可通过调整光线参数优化效果。


### 8.7. 例题:球体映射
- 球体映射遵循相同明暗原理：亮部区域凸起更明显，暗部区域凹陷更显著。调整图形长宽至画面边缘后映射，可形成环形立体结构。
- 渲染注意事项：
    - 直接栅格化会导致边缘锯齿和杂点过多，必须通过3D渲染功能处理。
    - 渲染过程中禁止移动鼠标，否则需重新渲染。
    - 最终成图需手动修复瑕疵：使用羽化选区复制局部覆盖缺陷区域。
- 材质应用示例：新建绿色图层执行圆环映射，可更换为钢丝网等材质，材质编辑属进阶内容需后续讲解。
- 核心知识点：3D模型创建的核心功能为"从所选图层新建3D模型"，其余功能为辅助性质。
