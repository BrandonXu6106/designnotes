3D功能中从所选图层新建3D是关键命令，需配合窗口菜单中的3D和属性面板使用。以文字图层为例：
- 新建文字图层并输入单字母（如"H"）
- 调整背景色为灰色，文字颜色设置为高对比色（如金色或蓝色）
- 3D面板与属性面板联动可控制三维效果


## 1. 3D菜单﻿
- 3D面板与属性面板专用于三维图层控制
- 点击从所选图层新建3D模型后，文字将转换为具有厚度的三维对象
- 创建方式说明：
    - 通过图层右键菜单创建
    - 通过3D面板选择3D模型而非明信片模式
- 路径/选区同样适用此功能


## 2. 3D面板功能讲解

|   |   |   |
|---|---|---|
|控件类型|功能说明|操作效果|
|环绕移动3D相机|改变观察视角|物体位置不变，视角360度旋转|
|平移3D相机|调整视距|模拟远近观察效果|
|移动3D相机|改变物体位置|实际移动三维对象|

### 2.1. 环绕移动3D相机
环绕移动3D相机介绍
- 环绕移动3D相机通过鼠标拖拽实现多角度观察，保持物体空间位置不变
- 视角变化与效果展示﻿04:06﻿
- 视角模拟：
    - 俯视角度对应直升机航拍效果
    - 仰视角度模拟地面观察高层建筑
- 坐标系统：红蓝线交叉点为三维空间中心基准
- 坐标中心点与3D图层﻿06:00﻿

三维图层中心点自动对齐至文字几何中心，红蓝网格代表空间基准平面
- 相机移动与物体关系﻿07:01﻿

视角移动与物体移动本质区别：
- 前者仅改变观察位置（如环绕建筑行走）
- 后者实际改变物体空间坐标
- 相机与物体移动的区别﻿07:52﻿

渲染结果差异：
- 相机移动保持物体原始状态
- 物体移动会改变三维模型实际朝向


### 2.2. 平移3D相机

|   |   |   |
|---|---|---|
|操作方向|视觉等效|参数变化|
|垂直拖动|调整观察高度|视平面上下偏移|
|水平拖动|侧方位移动|视平面左右平移|
|纵深拖动|改变观察距离|模拟镜头推拉效果|

### 2.3. 轴的含义
- X轴：水平方向的理解与操作﻿10:21﻿

X轴（红色）控制水平移动，黄色高亮时仅允许单向平移
- Y轴：垂直移动的理解与操作﻿10:53﻿

Y轴（绿色）实现垂直位移，可突破网格平面上下移动
- Z轴：纵深移动的理解与操作﻿11:10﻿

Z轴（蓝色）调节纵深位置，实际改变物体前后空间关系
- 视角的前后关系与放大缩小﻿11:50﻿

缩放操作需通过中心灰色方块实现，与视角调整有本质区别

- 控件：控制的零件﻿12:30﻿

三维控件包含：
- 箭头：轴向移动
- 弧线：轴向旋转
- 方块：轴向缩放
- 例题1:围绕x、y、z轴进行旋转﻿13:16﻿

旋转轴逻辑：
- X轴控件对应Y轴旋转
- Y轴控件对应Z轴旋转
- Z轴控件对应X轴旋转
- 例题2:沿着x、y、z轴缩放﻿14:00﻿

非等比缩放通过末端方块实现，保持其他轴向尺寸不变
- 恢复默认相机与练习建议﻿17:07﻿
- 恢复默认相机后，点击面板并输入字母h
- 调整字母颜色为金色
- 选中图层后直接创建


### 2.4. 属性面板功能讲解
- 面板分为3D板块和属性板块
    - 3D板块包含四个图标：
        - 第一个图标为参数汇总，包含视图、网格系统、材质系统、灯光系统
        - 后三个图标分别为网格、材质、灯光的独立编辑入口
- 点击不同图标时，上方属性面板会同步切换对应属性
    - 点击灯光图标显示灯光属性
    - 点击材质图标显示材质属性
    - 点击网格图标显示网格属性
- 环境
	- 环境的概念与作用
	- 环境与无限光的作用是为物体提供光线
	    - 点击环境时，鼠标可转动光线方向
	    - 取消勾选环境光后，光线消失
	    - 点击视图时，鼠标可移动整个场景
	- 全局环境色的默认与调整﻿20:38﻿
	- 全局环境色默认为黑色，通常无需调整
	- 环境色通过灯光系统补充光感
- 灯光的编辑与替换纹理
	- 灯光可编辑纹理或替换贴图
	    - 修改灯光贴图（如用白色画笔增强局部光）后保存，画面亮度会同步变化
	    - 移除灯光贴图后，画面恢复默认状态
- 灯光的转动与图形转动﻿
	- 转动灯光或图形可调整光影效果
	    - 灯光方向影响物体明暗面分布
	    - 图形旋转可改变受光角度
- 光源的调整与层次感
	- 点光源调整可优化光线舒适度
	    - 通过移动点光源位置增强物体层次感
	    - 需确保不同面有明显明暗区分
- 贴图的更改与效果观察
	- 环境贴图可替换为自定义图片
	    - 替换后保存（Ctrl+S）即时观察光线变化
	    - 强烈光线可能导致画面过曝，需调整贴图范围或恢复默认
- 网格系统﻿
	- 网格系统决定物体造型，为重要功能模块
- 网格系统与物体造型
	- 网格系统用于微调物体基础结构
	    - 默认相机视角下调整图形旋转轴
- 网格系统中的图形旋转﻿
	- 旋转图形时需区分场景坐标轴与物体坐标轴
	    - 点击图形后旋转仅影响物体自身
	    - 未点击图形时旋转影响整个场景
- 捕捉阴影与投影

| 功能   | 作用           | 关联性           |
| ---- | ------------ | ------------- |
| 捕捉阴影 | 控制物体自身阴影显示   | 关闭后阴影消失       |
| 投影   | 控制物体投射到地面的阴影 | 关闭投影后捕捉阴影同步失效 |

- 不可见与可见﻿
- 不可见选项用于隐藏图形显示，通常保持可见状态
- 投影的调整与去除
- 投影可根据场景需求关闭
    - 复杂场景中需单独控制影子效果
- 形状预测与环境光﻿
- 形状预设包含18种系统自带样式
    - 前12种为拉伸效果，后6种为旋转效果
    - 常用预设为第1、2、3种及圆环样式
- 应用案例﻿
- 例题:字母样式修改
- 形状预设应用示例：
    - 默认样式为平面加厚度（盖子）
    - 第二预设增加倒角效果
    - 第三至第十二预设提供不同倒角细节（圆弧、金属感、斜切等）
- 变形轴功能：
    - 深度参数控制拉伸方向（负值向前，正值向后）
    - 锥度参数调整底部大小（值越大底部越宽）
- 弯曲与切变效果：
    - 水平角度控制左右弯曲方向
    - 切变模式将弯曲转为直线形变
- 盖子面板功能讲解﻿
	- 盖子面板包含以下核心功能：
		- 盖子厚度控制
		- 作用：为3D字母（如示例中的"HB"）添加纵深厚度
		- 原理：通过前后盖面封闭模型避免空心结构
- 斜面参数调节

| 参数  | 功能         | 视觉表现         |
| --- | ---------- | ------------ |
| 宽度  | 控制斜面横向延伸范围 | 斜面与主体的接触面积变化 |
| 角度  | 调整斜面与主体的夹角 | 斜面倾斜度变化      |

- 等高线特效
	- 功能：通过剖面曲线编辑器改变斜面截面形态
	- 操作：支持手动拖拽节点创建自定义倒角效果
- 膨胀控制
	- 强度：调节盖面中心区域的凹凸幅度（正值凸起/负值凹陷）
	- 角度：影响膨胀效果的轴向分布
- 坐标系统
	- 交互方式：主要通过手动拖拽模型观察实时角度变化
- 复位功能：
	- 复位坐标：恢复初始空间位置
	- 移到地面：自动对齐网格基准面


注意事项：
- 背面盖面参数默认隐藏（因视角遮挡）
- 坐标数值输入框实际使用频率较低
- 膨胀效果需配合强度参数才能显现
