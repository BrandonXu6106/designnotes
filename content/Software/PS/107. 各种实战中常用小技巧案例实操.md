## 1. 实战小技巧﻿
PS软件通过滤镜、命令、特效等组合可产生多种实用技巧。技巧虽多但底层逻辑相通，掌握原理后即可举一反三。常见应用场景包括：
- 斑点去除（配合蒙尘划痕滤镜）
- 眼镜反光处理（明暗与色彩分层调整）
- 彩色图片与路径结合生成艺术文字
- 材质球制作立体字效果


### 1.1. 图片杂点去除
![202607110006517.png|232](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607110006517.png)
- 备份原图层是处理前的必要步骤，避免操作不可逆。
- **蒙尘划痕滤镜**：
	- 半径：通过调整半径==模糊杂点==
	- ⭐⭐⭐⭐**阈值**：参数控制==纹理保留==范围
	  ![202607110008309.png|290](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607110008309.png)
- 精细化处理：
	- 结合==黑色蒙版==与==白色画笔==，局部修复残留杂点。
- 商业级修图要求：需通过复制纹理区域（Ctrl+J），并对齐修补细节缺失部分。


### 1.2. 眼镜反光去除

| 处理步骤 | 技术要点                             | 工具/命令       |
| ---- | -------------------------------- | ----------- |
| 明暗调整 | 通过==黑白观察层==分析亮度差异，使用==曲线==压暗高光区域 | 曲线调整层+剪切蒙版  |
| 色彩替换 | 吸取周围肤色，用==颜色混合模式==覆盖反光区域         | 画笔工具+颜色混合模式 |
| 细节修补 | 结合修补工具与==图章工具==修复边缘过渡，补充缺失睫毛     | 修补工具/仿制图章工具 |
| 整体协调 | 调整嘴唇色彩（混合颜色带控制明暗），牙齿明度微调（色相饱和度）  | 色相饱和度/混合选项  |
核心逻辑：先解决==明暗==关系再处理==色彩==细节，商业修图需遵循分层渐进式修正原则。

### 1.3. 文字去除
![202607110129439.png|520](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607110129439.png)
- 底层原理：通过选区工具精确选择文字区域是去除文字的关键步骤。
- 选区工具选择：可使用==魔棒工具==或==色彩范围==功能选取文字区域，调整容差参数可优化选区精度。
- 选区扩展：若选区未完全覆盖文字透明边缘，需通过==选择>修改>扩展==功能补充选区范围（建议扩展3像素）。
- 内容识别填充：执行==编辑菜单>填充>内容识别==可智能替换文字区域，但存在边缘瑕疵风险。
- 瑕疵修复：对于填充后的局部缺陷，可使用涂抹工具或==液化==工具微调边缘，或采用复制邻近纹理覆盖修补的方法。
- 内容识别填充

| 处理步骤   | 技术要点                             | 局限性                                |
| ------ | -------------------------------- | ---------------------------------- |
| 初始选区建立 | 使用魔棒工具选取目标区域，需扩展1像素以覆盖边缘         | 复杂纹理区域（如拉链）易产生选区偏差                 |
| 内容识别填充 | 按Ctrl+Shift+F5调用填充功能，优先测试内容识别模式  | 高对比纹理背景会导致填充后出现杂乱色块（如示例中的"花老虎"效果）  |
| 人工精修   | 分区域复制邻近纹理→羽化边缘→变形对齐→合并图层→蒙版柔化过渡  | 需耗费大量时间处理光影过渡，皮衣类硬质材质需特别注意明暗交界线自然度 |
| 细节强化   | 使用减淡工具提亮局部→仿制图章修补断裂纹理→修补工具校正阴影区域 | 完全还原原始纹理结构较困难，需以视觉可接受为验收标准         |

### 1.4. 制作彩色描边字
- 素材要求：背景需具备高饱和度与==丰富色彩变化==
  ![202607110139942.png|265](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607110139942.png)
- 路径基础：需先创建==文字路径==，路径曲率直接影响最终效果的自然度。
- 工具提前配置：选择涂抹工具时，硬度设为100%，强度建议85%-90%，勾选"对所有图层取样"确保色彩采集。
- 路径描边：应用涂抹工具，模拟压力选项可生成两头细中间粗的笔触。
- 效果控制：画笔大小（建议25-40像素）决定描边粗细，角度参数影响色彩取样方向，1%间距设置保证描边连续性。
  ![202607110139709.png|274](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607110139709.png)


### 1.5. 材质球写字(三维效果)
![202607110140210.png|329](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607110140210.png)
- 材质小球写字效果可通过==混合器画笔工具==实现，需新建图层并选择混合器画笔工具。
- ==采样==时需使用==硬边缘画笔==：柔边缘画笔会导致采样范围不准确，硬边缘画笔可精准采样单个材质球。
	- 采样方法：按住`ALT键`点击材质球完成采样，采样后即可用混合器画笔绘制具有三维立体感的文字（如"hello"）。
	  ![202607110142746.png|288](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607110142746.png)
- 参数调整影响效果：
    - 潮湿参数：数值越小，边缘质感越弱；数值最大时效果最明显。
    - 载入参数：与潮湿参数联动，调整后效果变化相近。
- **混合参数**注意事项：
    - 开启混合会导致绘制颜色==与背景色混合==（如白色背景会使绘制内容淡化）。
    - 黑色背景下混合会使色彩变暗，底色直接影响最终色彩呈现（如红色底色会泛红）。
- 核心原理：通过明暗关系处理和材质球定义实现三维效果，需重点掌握硬边缘采样和参数逻辑。
