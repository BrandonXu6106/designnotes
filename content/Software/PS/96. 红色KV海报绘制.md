# 案例-红色KV海报
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607091730823.jpg)

- **分析流程**：先分析设计元素构成，再逐步调整色彩和发光效果。
- **背景色调处理**：使用多种明暗红色调组合，避免单一色调显得单调。
- **线条处理**：通过极坐标命令将直线转换为圆形线条。
- **光线效果制作**：结合滤镜的内发光和外发光功能创建光线效果。
- **蒙版应用**：利用蒙版进行局部擦除，控制光效的显示范围。
- **变形融合**：通过变形操作将不同元素融合在一起。


## 1. 绘制背景
>- 绘制前准备；新建文件尺寸：30cm×15cm，200分辨率

- **图层操作**：新建图层，==填充==颜色。
	- **颜色选择**：建议避免过灰的==红色==，选择稍深的颜色。
  ![202607091737976.png|300](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607091737976.png)
- **暗色调﻿添加**﻿：
    - **新建图层**：创建新图层用于添加暗色调
    - **颜色选择**：==同色系==深色
    - **画笔工具**：使用画笔工具涂抹暗色区域
    - **图层调整**：通过==旋转和放大==调整暗色区域
    - **图层合并**：将多个暗色调图层==合并==
    - **高斯模糊**：应用滤镜==模糊==使过渡更自然
      ![202607091740432.png|299](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607091740432.png)
- **过渡处理**：画面缺乏明暗过渡的立体感
    - **图层处理**：通过==新建图层==调整局部亮度
    - **颜色选择(两层)**：最后合并双层
	    - **底层**：使用==橙色==系作为基础色调
	    - **中心点层**：并选择更亮的==黄色==在中心进行叠加
	      ![202607091743644.png|323](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607091743644.png)
    - **混合模式**：使用==滤色==模式增强光效亮度。
    - **变形调整**：通过`ctrl+t`进行==大小==调整、==压扁和旋转==，避免过于统一。
    - **透明度控制**：根据需要降低图层透明度以软化效果。
      ![202607091745805.png|343](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607091745805.png)
