# 案例—化妆品海报(非常难)
 ![202607100007049.jpg|236](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607100007049.jpg)
- 课程内容：化妆品海报绘制，第98节课
- 难度系数：非常大，时间需求长
- 制作方式：全程手绘，未使用素材
- 技术要点：图层混合模式应用
- 绘制重点：瓶子光影处理
- 画布设置：20×28厘米，200分辨率
- 工作流程：边分析原理边实操
- 文案处理：保留现有文字不重制



##### 1.新建图层和背景填充﻿01:27﻿
- 新建图层: 在软件中创建新的工作图层
- 背景填充: 使用深咖色或黑色填充背景层
- 颜色选择: 选择接近黑色的深咖色作为基础色调
- 快捷键操作: 使用Ctrl+T进行图层放大操作
- 图层对齐: 将图层居中对齐于画布中央
- 透明度调整: 适当降低图层不透明度
- 图层合并: 将多个图层合并为一个图层
- 画笔工具: 使用画笔工具进行基础绘制
- 快速操作: 通过快捷键实现高效图层调整
- 一次性定型: 对不需要修改的图层进行最终确定

##### 2.光效图层的制作﻿02:26﻿

###### 1) 光效图层绘制🌟

- 新建图层：选择暗色调并填充发红色调作为基础。
- 画笔工具使用：调出画笔工具并填充接近黄色的颜色。
- 图层合并：合并多个图层后改为绿色模式以过滤暗色。
- 图层复制：复制图层作为备用并调整颜色为红色。
- 形状调整：压扁并拉长图层以形成光效。
- 居中对齐：使用ctrl+a全选并居中对齐图层。
- 光效增强：通过复制图层和更改模式（如线性简单）增强光效。
- 羽化处理：使用羽化功能（如10像素）柔化边缘。
- 图层管理：将多个光效图层打组并命名以便管理。
- 光线调整：调整光线位置和大小以确保可见性和效果。

###### 2) 外面光效图层绘制🌟🌟﻿06:11﻿

- 图层复制：通过复制现有图层创建新光效层。
- 形状调整：使用压扁和拉伸操作调整光效形状。
- 极坐标滤镜：应用极坐标滤镜创建环形光效。
- 选区操作：通过框选和全选进行精确编辑。
- 图层模式：使用颜色减淡和线性减淡模式增强光效。
- 蒙版应用：添加蒙版控制光效显示范围。
- 色彩平衡：调整色彩平衡控制光效色调。
- 合并图层：合并相关图层简化操作流程。
- 细节优化：通过反复尝试调整光效细节。
- 裁切工具：使用裁切工具去除多余部分。

##### 3.中间颗粒感图层绘制﻿12:13﻿

###### 1) 绘制金色颗粒﻿12:21﻿

- 新建图层：使用画笔工具前需新建独立图层
- 颜色选取：吸取金沙质感的中黄色作为基础色
- 颗粒绘制：通过点状笔触模拟金沙颗粒效果
- 图层复制：Ctrl+J复制图层增强中心亮度
- 明度调整：Ctrl+U提高复制层明度制造高光
- 色彩修正：通过色彩平衡(Ctrl+B)增加黄红色调
- 曲线调整：Ctrl+M提升整体亮度强化金属感
- 图层排序：将金沙层置于圆形元素下方

###### 2) 绘制杂点🌟🌟🌟﻿13:16﻿

- 杂点制作方法：通过椭圆工具创建描边形状，关闭填色并设置描边粗细，利用羽化值和溶解模式生成杂点效果。
- 杂点控制技巧：通过调整不透明度控制杂点数量，使用图层合并（ctrl+e）和复制（ctrl+j）增强层次感。
- 颜色处理策略：填充金色调时需多层叠加，通过模式（如绿色模式）和色相/饱和度（ctrl+u）调整明暗对比。
- 纹理变形技术：使用变形工具拆分节点调整弧度，结合叠加模式和高斯模糊（3像素）模拟自然纹理。
- 边缘处理步骤：添加羽化选区（5-10像素）并创建蒙版，隐藏外围纹理以聚焦中心效果。

##### 4.气泡的绘制﻿24:04﻿

###### 1) 新建图层填充颜色与创建圆形选区﻿24:10﻿

- 新建图层:讲解中演示新建图层操作
- 填充颜色:选择黑色填充以便观察效果
- 创建选区:使用圆形工具绘制圆形选区
- 二次填充:在圆形选区内填充白色

###### 2) 选区保留填充白色与内发光设置﻿24:28﻿

- 选区保留操作：载入选区后点击保留功能
- 填充关闭步骤：使用Ctrl+D快捷键关闭填充
- 内发光设置：双击图层打开内发光效果面板
- 发光参数调整：不透明度70-80%，大小20-25像素
- 发光颜色选择：接近白色略带黄色的光效

###### 3) 栅格化图层样式与高光制作﻿25:06﻿

- 栅格化图层样式:右击图层选择"栅格化图层样式"将效果转为像素
- 高光制作工具:使用画笔工具绘制基础形状
- 高光形状调整:按Ctrl+T自由变换压扁形状，右击选择"变形"调整弧度
- 高光细节处理:通过多次变形操作逐步完善高光形态
- 高光发散性:需注意高光边缘的自然过渡效果

###### 4) 高光发散性处理与光线制作﻿25:45﻿

- 高光发散效果制作:通过选区填充白色并应用风格化风滤镜实现光线发散效果
- 风滤镜应用技巧:连续应用风滤镜2-3次使边缘效果更自然
- 光线旋转处理:使用Ctrl+T自由变换工具调整光线角度和比例
- 极坐标转换:通过滤镜扭曲中的极坐标功能将直线光线转换为放射状
- 图层管理:新建独立图层处理光线效果便于后期调整
- 效果控制要点:避免过度规则化处理保持自然发散效果

###### 5) 光线变形处理与多余部分删减﻿26:59﻿

- 光线变形处理：通过压扁和拉透视调整光线形状。
- 多余部分删减：删除画面中不需要的部分以优化效果。
- 变形操作步骤：右击选择变形，调整形状后确认。
- 透视调整技巧：轻微拉动以增强光线透视感。
- 光线大小控制：使用快捷键调整光线大小以适应画面。

###### 6) 高反光制作与不透明度调整﻿27:31﻿

- 高反光制作:通过新建图层、选框操作和变形处理实现高反光效果
- 变形处理技巧:使用ctrl+t键调整大小后右击进行变形处理，拉出适当弧度
- 不透明度调整:降低图层不透明度以控制反光强度，根据实际效果灵活调整
- 操作步骤:选框→新建图层→合并→变形→调整不透明度
- 标准说明:高反光效果没有固定标准，主要依靠视觉感受进行调整

###### 7) 球体光泽添加与颜色填充﻿28:21﻿

- 光泽添加方法：新建图层，使用画笔工具设置不透明度20-30%添加高光点。
- 高光调整技巧：通过Ctrl+T自由变换工具缩放/压扁高光形状，可多次叠加不同大小高光点。
- 颜色填充原则：根据物体基础色选择相近色（如黄色系）进行局部色彩强化。
- 图层管理策略：通过隐藏/显示图层对比观察光泽效果，保持非破坏性编辑。

###### 8) 球体透明度调整与位置摆放﻿29:40﻿

- 图层合并：使用ctrl+e快捷键合并图层，简化图层结构。
- 图层删除：删除不需要的黑色图层，保留球体图层。
- 图层命名：将合并后的图层命名为“球体”，便于识别和管理。
- 位置调整：使用ctrl+t快捷键旋转和调整球体位置，确保摆放合适。
- 透明度调整：通过ctrl+j复制图层增加不透明度，改善球体透明度过高的问题。
- 多层合并：多次复制并合并图层（ctrl+j和ctrl+e），增强球体视觉效果。
- 大小调整：使用ctrl+t调整球体大小，使其与场景协调。
- 底色优化：观察球体底色，调整至合适的明暗程度，避免过于透明。

###### 9) 球体底色调整与模式修改﻿30:48﻿

- 选区创建：在球体下方拉出选区并新建图层
- 颜色填充：使用同色系暗色调（如红色系）填充选区
- 图层模式：正片叠底模式可增强阴影效果，叠加模式也可作为备选
- 透明度调整：降低不透明度使效果更自然
- 视觉层次：暗色调底层能解决球体"漂浮感"问题
- 图层管理：完成效果后将相关图层打组命名为"球体"
- 工作流程：隐藏已完成组，优先处理基础元素（如瓶子）再调整附属元素

##### 5.瓶子的绘制﻿31:44﻿

- 新建图层：绘制前需新建图层并填充黑色作为背景。
- 工具选择：使用矩形工具绘制瓶子的基本结构。
- 圆角处理：上方两角设置为圆弧形（0.1-0.2厘米），下方两角保持方形。
- 描边设置：关闭描边功能以简化图形。
- 填色准备：完成基础结构后需进行填色处理。

###### 1) 瓶子结构图层的制作﻿32:44﻿

- 图层不透明度与内发光设置
    - 不透明度调整:双击图层关闭不透明度
    - 内发光设置:先添加内发光效果
    - 发光颜色选择:根据背景色调整发光颜色(黄色背景用偏黄色光)
    - 材质影响原理:透明材质会受背景色影响
    - 参数微调技巧:发光颜色需适当增加背景色调
    - 操作确认步骤:调整后点击确定完成设置
- 高光处理与剪切蒙版应用﻿33:14﻿
    - 高光处理步骤：新建图层并选择白色画笔进行点绘。
    - 剪切蒙版应用条件：下方图层为透明形状图层时蒙版会消失。
    - 图层操作技巧：右击创建剪切蒙版前需确认下方图层属性。
    - 撤销操作应用：在错误应用剪切蒙版时使用撤销功能恢复。
    - 内发光保留方法：在调整图层样式时需注意保留特定效果。
- 瓶盖高光与反光效果制作﻿34:05﻿
    - 剪切蒙版应用：右击创建剪切蒙版，双击图层取消勾选"剪切模板混合成组"实现效果分离。
    - 高光颜色选择：使用接近白色的颜色，通过画笔工具绘制基础高光形状。
    - 高光层次处理：复制图层后缩小，使用高斯模糊滤镜制作次高光，调整不透明度至50%左右。
    - 暗色调添加：复制高光图层填充暗色系，调整大小和位置形成明暗对比。
    - 反光制作技巧：复制高光图层压扁拉远，降低不透明度至40-50%模拟半透明反光效果。
    - 图层管理要点：保持各效果图层独立不合并，便于后期调整。
- 瓶盖图层调整与合并﻿36:46﻿
    - 图层分组：将瓶盖图层进行分组管理，便于后续操作。
    - 快捷键调整：使用ctrl+t键对瓶盖图层进行大小调整。
    - 图层命名：为瓶盖图层命名，方便识别和管理。
    - 图层放置：调整瓶盖图层位置，避免过大或遮挡其他元素。
    - 瓶身绘制：开始绘制瓶身部分，作为瓶盖的配套元素。
- 瓶身圆角矩形绘制与颜色填充﻿37:09﻿
    - 工具选择：使用圆角矩形工具绘制瓶身结构
    - 描边处理：关闭描边属性以简化图形
    - 颜色填充：为瓶身选择适当的基础颜色
    - 圆角调整：通过属性面板微调圆角数值（如0.2）
    - 图层管理：在黑色背景图层上方新建工作图层
    - 视觉参考：利用背景图层辅助观察图形效果
- 瓶身高光与暗部效果制作﻿37:54﻿
    - 高光制作步骤：新建图层填充高光颜色，创建剪切蒙版，调整宽度。
    - 暗部制作方法：复制高光图层，锁定透明区域填充暗色，使用ctrl+m键调整明暗。
    - 边缘处理技巧：复制亮色图层，删除部分区域制造亮边，应用高斯模糊（1像素）。
    - 颜色调整策略：选择比原色更暗的颜色填充，确保光泽不均匀以增强真实感。
    - 图层操作要点：通过复制和调整图层位置，实现高光与暗部的层次效果。
- 瓶身光泽与层次感调整﻿39:18﻿
    - 羽化操作：使用ctrl+alt+2快捷键进行羽化处理，用于观察效果。
    - 高光生成：通过ctrl+m键压按产生不规则高光，不透明度建议降至80%。
    - 图层复制与翻转：复制图层后右击进行水平翻转，避免金属光泽完全对称。
    - 光泽观察：金属光泽需多观察，光线强烈时光泽会非常硬。
    - 高光与暗部添加：反复添加高光和暗部，调整不透明度和模糊度。
    - 层次感调整：通过复制、缩小、移动图层增加层次感，需反复调整。
    - 颜色调整：合并图层后使用ctrl+b键添加黄色和红色调。
    - 反复观察：强调反复观察和调整的重要性，确保过渡自然。
- 瓶盖描边与光泽处理﻿42:45﻿
    - 选区操作:带入选区并新建图层进行后续处理
    - 描边设置:右击选择描边，设置2像素白边，位置选择内部或居中
    - 光泽处理:通过高斯模糊添加光泽效果，模糊值设为0.5-1像素
    - 剪切蒙版:右击创建剪切蒙版控制效果范围
    - 细节调整:使用橡皮擦工具擦除多余部分，重点处理暗部和高光区域
    - 图层合并:完成调整后合并相关图层
- 瓶盖与瓶身最终调整﻿43:34﻿
    - 图层复制：使用ctrl+t键复制并调整图层大小。
    - 图层调整：将复制图层缩小并放置到合适位置。
    - 图层压扁：对复制图层进行压扁处理以适应设计需求。
    - 图层排列：调整图层顺序，确保瓶盖位于正确位置。
    - 颜色调整：修改瓶盖内发光颜色，减少黄色，增加白色。
    - 最终定位：将调整后的瓶盖精确放置到瓶身上方或下方。

###### 2) 瓶子高光图层的制作﻿44:26﻿

- 图层备份：复制瓶盖图层作为备份
- 图层合并：使用ctrl+e合并上层图层
- 选区处理：框选特定区域后羽化10像素
- 层次创建：通过复制和删除操作产生两个层次
- 效果预览：隐藏黑底查看实际效果
- 颜色调整：使用ctrl+m提亮，ctrl+b调节黄色，ctrl+u降低饱和度
- 瓶身绘制：完成高光图层后进入瓶身绘制阶段

###### 3) 瓶子身图层的制作﻿45:48﻿

- 瓶身绘制与颜色填充﻿46:01﻿
    - 瓶身绘制步骤：使用圆角矩形工具绘制瓶身轮廓，调整大小和位置。
    - 图形调整技巧：通过Ctrl+T调整图形大小，Ctrl+A全选后居中对齐。
    - 圆角处理：在绘制圆角矩形时，适当拉出圆角以符合瓶身设计。
    - 描边处理：完成绘制后，需去掉图形的描边以保持设计简洁。
    - 颜色填充方法：右击图层选择栅格化，锁定透明区域后填充所需颜色。
    - 颜色选择策略：瓶身填充暗色调黄色，部分区域填充接近白色以增强视觉效果。
- 瓶身渐变与内阴影设置﻿46:56﻿
    - 渐变设置：将不透明度调整为100%，通过拉渐变工具创建渐变效果。
    - 内阴影应用：添加内阴影效果，调整阻塞参数以控制阴影范围。
    - 颜色调整：选择较深颜色作为内阴影，增强立体感。
    - 选区处理：使用变换选区或收缩选区功能修改选区范围。
    - 蒙版使用：添加蒙版后用画笔或橡皮擦工具擦除部分内容，调整硬度和不透明度。
    - 栅格化图层样式：将内阴影效果栅格化以便进一步编辑。
    - 光线效果准备：在排布光线效果前，先处理中间部分的透明度。
    - 工具选择：根据需求选择画笔或橡皮擦工具进行细节调整。
    - 不规则边缘处理：通过选区或擦除工具处理不规则边缘。
    - 分步操作：先完成水纹效果再处理其他细节，确保工作流程有序。
