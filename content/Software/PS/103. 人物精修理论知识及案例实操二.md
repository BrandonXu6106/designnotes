## 1. 双曲线磨皮﻿
通道配合高反差保留是一种磨皮方法，而另一种方法更为快捷且效果良好。
**像素级别修图**需精细处理，其优点是修图质量极高，缺点是耗时较长。
- 例如**双曲线修图**需大量时间，通常适用于明星代言或品牌精修需求，普通商业修图较少采用。
- 双曲线磨皮需使用==两根曲线==调整==皮肤质感==与==明暗关系==。


### 1.1. 双曲线磨皮的基本概念﻿
双曲线通过两根曲线分别修复皮肤质感与明暗关系，核心目标是质感优化和明暗平衡。

### 1.2. 图片观察与初步处理﻿
- 初步调整：通过曲线提亮整体画面并降低饱和度。
- 合并图层：完成基础调整后合并图层。


### 1.3. 标志性特征的处理﻿
- 标志性特征保留：如人物有标志性痣（如孙俪嘴角痣），需保留；非标志性瑕疵可用修补工具去除。


### 1.4. 双曲线的建立与命名﻿
- 建立两根曲线：分别命名为“调亮”与“调暗”，暂不调整参数。
  ![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607102304253.png)


### 1.6. 肤色统一与明暗关系处理
- 肤色均衡：通过提亮凹陷区域、压暗凸起区域实现肤色统一。
- 像素级修图：需逐点处理皮肤瑕疵，工作量极大。


### 1.7. 观察组建立
- 黑白观察层：转换为黑白单色便于观察明暗对比。
- 增强对比：通过曲线强化黑白对比，辅助修图后需删除观察组。

### 1.8. 例题1:双曲线修图过程﻿

| 操作步骤    | 功能说明                          |
| ------- | ----------------------------- |
| 调暗曲线    | 压暗画面中过亮区域，蒙版反向后用白色画笔局部涂抹调整。   |
| 调亮曲线    | 提亮画面中过暗区域，同样通过蒙版反向与白色画笔控制范围。  |
| 流量与不透明度 | 需设置为20%左右，少量多次涂抹以避免过度调整。      |
| 光影重塑    | 通过双曲线重新塑造鼻尖、唇部、苹果肌等高光区域的明暗关系。 |

### 痘印的淡化
痘印淡化需精细处理，主要分为凸起型和凹陷型。凹陷型痘印因形成阴影而显色深，需通过提亮操作消除明暗对比。具体操作步骤如下：
- 凹陷型痘印处理：使用曲线工具创建提亮图层，用画笔在痘印阴影处反复涂抹，逐步提升亮度至与周围肤色一致。
- 顽固痘印补充处理：若提亮效果不足，需配合修补工具选取邻近肤色覆盖痘印区域。
- 明暗平衡调整：同步使用压暗曲线处理局部过亮区域，确保整体肤色过渡自然。


### 1.10. 例题2:双曲线修图综合应用
双曲线修图的核心是通过分图层处理明暗关系：
- 提亮组操作：针对暗斑区域，用低透明度画笔多次涂抹，逐步减弱色差。
- 压暗组操作：对边缘高光区域进行适度压暗，增强与周边皮肤的融合度。
- 效果验证：通过开关观察组对比修图前后效果，修图质量与时间投入正相关，需保持像素级精细调整。


### 1.11. 图片清晰度与修图要求
商业级修图对素材清晰度有严格要求：

| 要素                                                 | 标准              | 常见问题          |
| -------------------------------------------------- | --------------- | ------------- |
| 原始图片分辨率                                            | 需支持放大3-5倍无锯齿    | 网络下载图片易出现边缘失真 |
| 修图工具选择                                             | 双曲线配合修补工具       | 单一工具无法处理顽固色斑  |
| 明暗处理原则                                             | 提亮暗部+压暗亮部实现均匀过渡 | 局部过度调整破坏整体协调性 |
| 操作要点：顽固色斑需结合选区修补，且所有调整需在全局观察模式下进行，避免局部优化影响整体色调一致性。 |                 |               |

### 1.12. 修图的最终效果与调整﻿
- 复制图层后去除面部明显纹理（法令纹、黑斑等），处理后的图层作为原图。
- 建立观察组：
    - 添加黑白图层便于观察整体光影走向，突出明暗对比。
    - 通过曲线工具加强对比，定位亮部与暗部以便后续像素级处理。
- 双曲线修图原理：
    - 第一根曲线压暗：针对观察组中识别的亮部区域进行压暗处理。
    - 第二根曲线提亮：对画面过暗区域进行提亮，实现光影平衡。
- 局部瑕疵处理：使用画笔工具对脂肪粒等突出瑕疵进行提亮或修补，需逐像素精细调整。
- 观察组删除：修图完成后需删除观察组，最终配合蒙尘划痕、高反差保留等工具增强质感与光影层次。


### 1.13. 蒙尘划痕与模糊处理﻿
- 蒙尘划痕应用：
    - 对光影层进行2像素模糊处理，通过蒙版控制作用区域（如鼻梁、额头等需平滑处）。
    - 保留纹理细节：鱼尾纹、皮肤质感等需避免过度模糊。
- 蒙版操作：
    - 使用白色画笔在蒙版上涂抹需模糊区域，实现局部柔化效果。
    - 对比观察模糊前后效果，确保过渡自然。


### 1.14. 高反差保留与质感增强﻿
- 高反差保留：
    - 设置2像素半径提取纹理，叠加线性光模式增强质感。
    - 通过蒙版精准控制纹理强化区域（如面部轮廓、毛孔等）。
- 明暗微调：
    - 添加曲线层调整整体对比度，亮部提亮、暗部压暗以突出立体感。


### 1.15. 色彩平衡与最终调色﻿
- 色彩平衡调整：
    - 勾选保留明度选项，避免调色影响原有光影关系。
    - 根据应用场景调整色调（如化妆品广告需减少黄色，服装广告可保留古铜色）。
- 分组管理图层：将修图步骤归类为光影、质感等组别，便于对比原始效果与调整后效果。


## 2. 中性灰磨皮
- 中性灰图层创建：
    - 填充50%灰度并设置为柔光模式，用于非破坏性光影调整。
- 加深与减淡工具应用：
    - 加深工具压暗过亮高光（如鼻梁、嘴唇）。
    - 减淡工具提亮暗部凹陷区域，曝光度控制在10%以内以实现自然过渡。
- 蒙版修复：对误操作区域通过蒙版擦除恢复原始光影。
- 与双曲线对比：中性灰适合大范围光影调整，双曲线更适合局部精细控制。
- 商业修图局限性：手动修图效率低但个性化强，影楼多依赖插件批量处理。
