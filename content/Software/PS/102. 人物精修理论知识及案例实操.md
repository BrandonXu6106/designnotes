## 1. 课前概述

### 1.1. 修图需求与场景考虑
修图主要针对人物皮肤处理，但并非所有场景都需要将皮肤修得光滑细腻。例如远景人物图片无需面部特写精修。海报设计需考虑行业特性，如美容行业海报需呈现牛奶丝滑质感，肤色需调亮且略带粉红。运动类场景则需保留皮肤自然质感，过度修饰反而不符合主题需求。

### 1.2. 修图风格与场景适配
图片修饰必须符合使用场景特性：
- 商业代言类（如化妆品/服装）需呈现清新轻盈感，肤色过渡需丝滑匀称
- 运动健身类需强化力量感，通过增强肌肉线条、关节明暗对比实现
- 专业摄影作品需保留人物原始特征，如运动员海报需刻意强化青筋和腹肌沟壑

光影处理原则：
- 柔和光影适用于忧郁/文艺主题（如玻璃色调海报）
- 强烈对比适用于力量型主题（如水泥背景健身宣传）


### 1.3. 修图保留人物特性
人物修图需保留核心特征：
- 明星肖像必须维持辨识度（如保留标志性痣或体型特征）
- 性别差异处理：男性主要去除斑点，女性需精细处理雀斑、毛孔及毛发细节
- 表情肌理解：咬肌暗部强化可表现咬紧牙关的动态感


### 1.4. 修图风格与人物类型
人物风格决定修图方向：
- 清新/糖果型女性需唯美修饰
- 力量型女性需保留肌肉线条
- 中东人物需保持土黄色肤色基调


## 2. 皮肤修图﻿
专业修图案例特征分析：
- 中东人物肖像保留粗大毛孔和标志性痣，肤色以黄为主略带红
- 黑白摄影作品故意保留雀斑以契合影像质感
- 发丝处理需配合景深效果，清晰与模糊区域需明确区分


修图核心原则：根据应用场景（化妆品/职场/运动/货运等行业）调整修饰程度，适当保留沧桑感或力量感等特征。本节重点为掌握场景化修图判断标准。

## 3. 案例实操﻿

### 3.1. 辅助线调节
图像预处理流程：
- 通过辅助线校正人物倾斜问题
- 优先完成主体抠图再处理细节


### 3.2. 选区抠图
抠图技术要点：
- 钢笔工具创建基础选区后复制图层
- 通道抠图选择对比强烈的绿色通道
- 复制通道后需载入选区并扩展选取范围


### 3.3. 色阶调节﻿
通道色阶调整规范：
- 压暗整体色调时需全局观察发丝与背景的对比度
- 提亮背景时灰色滑块需左移以增强区分度
- 保持高光区域与暗部的平衡过渡


### 3.4. 套索工具选择﻿
局部精细化处理步骤：
- 使用套索工具单独选取边缘区域
- 二次色阶调整时需强化亮部抑制暗调
- 无法抠出的杂发需后续修补处理


### 3.5. 填充白色
发丝分离技术：
- 对非发丝区域填充白色建立蒙版基础
- 载入选区后内部填充黑色强化对比
- 边缘残留杂发需多次框选微调色阶


### 3.6. 填充黑色﻿
使用套索工具沿人物边缘绘制选区后填充黑色。需注意选区完整性，若遗漏部分（如耳朵区域）需补充选取。通过Ctrl+L调整色阶提亮白色区域，确保人物轮廓清晰。

### 3.7. 叠加模式涂抹发丝﻿
操作步骤：
- 选择叠加模式，用黑色画笔涂抹使发丝更清晰
- 细小发丝处理需手动绘制或复制扭曲
- 通道内按Ctrl+单击载入选区，Ctrl+Shift+I反选后返回RGB通道


### 3.8. 加蒙版﻿
操作流程：
- 添加图层蒙版删除背景
- 新建黑色背景层观察抠图效果
- 发丝边缘绿色残留需通过框选羽化处理（Ctrl+Alt+R调整羽化值）


### 3.9. 色彩平衡﻿
色彩调整要点：
- 色彩平衡不适用于杂色过多区域
- 改用剪切蒙版新建图层，需采样发丝颜色进行手动涂抹覆盖
- 画笔流量需调高以保证覆盖效果


### 3.10. 画笔涂抹发丝颜色﻿
涂抹发丝颜色与调整
- 操作规范：
- 吸管工具采用11×11平均取样确保颜色准确
- 不同明度区域需分层涂抹（暗部增加红调）
- 混合模式测试：叠加/正片叠底效果更佳
- 例题1:人物形体的改造﻿21:16﻿


面部结构调整重点：
- 右脸整体上提（眼角/嘴角对齐辅助线）
- 鼻梁歪斜需修正
- 液化前需分析原始比例问题
- 液化工具调整面部结构﻿21:48﻿

|   |   |   |
|---|---|---|
|部位|调整方向|操作要点|
|眼睛|右眼上提 - 5mm|使用向前变形工具微调|
|嘴唇|左唇角上提右角下压|保持中线对称|
|发际线|下压2mm|避免过度调整导致失真|
|下颌线|内收 - 8mm|配合脸部宽度协调|
- 调整细节与整体效果确认

液化后需检查：
- 面部肌肉走向自然度（苹果肌/太阳穴过渡）
- 保留30%原始特征避免失真
- 斑点需用修补工具处理


### 3.11. 修补工具去斑点﻿
斑点修复规范：
- 采样区域需与斑点周围肤色一致
- 大斑点优先用修补工具拖动覆盖
- 避免采样到高光/阴影异常区域


### 3.12. 污点修复画笔
小瑕疵处理要点：
- 污点修复画笔采用就近取样原则
- 流量控制在70%以下防止过度修复
- 发际线边缘需配合仿制图章工具


### 3.13. 面部肌肤质感处理﻿
油光处理技术：
- 颜色覆盖层：11×11平均取样肤色，30%流量涂抹
- 质感重建：
    - 复制背景层执行高反差保留（ - 5像素）
    - 线性光模式混合后剪切蒙版限定区域 
     - 质感移植：将正常皮肤纹理拖拽至油光区域
- 最终调和：组不透明度降至85%保留轻微高光


### 3.14. 鼻尖高光处理﻿
鼻尖区域通常较为光滑，毛孔较小。处理鼻尖高光需新建图层，选择修复画笔工具，取样模式设置为当前和下方图层。在鼻尖附近选取锚点进行纹理复制，保留适当高光效果。通过调整图层不透明度至40%可平衡油光与纹理表现。
关键步骤：
- 修复画笔工具需在空白图层操作
- 取样源必须包含下方图层纹理
- 不透明度调节是控制高光强度的核心参数


### 3.15. 面部磨皮﻿
磨皮流程分为质感层与光影层处理：
- 复制两个图层，分别命名为"质感"与"光影"
- 质感层执行高反差保留（半径以显现颗粒感为准）
- 光影层应用蒙尘与划痕滤镜（半径参数需谨慎控制）后添加黑色蒙版，用白色画笔局部提亮需要柔化的区域
- 线性光模式叠加质感层，通过蒙版排除头发等不需强质感区域

注意事项：
- 蒙版流量需控制在20%-30%避免过度处理
- 鼻部黑头需在蒙版中单独修饰
- 边缘过渡可通过高斯模糊优化


### 3.16. 光影与质感处理﻿
形体修正是基础步骤，需依次完成：
- 五官位置校准 - 皮肤质感重建 - 光影过渡优化
- 高反差保留与表面模糊的配合使用能实现真实肤质保留，处理边界时需配合羽化操作。


### 3.17. 增加高光

|   |   |   |
|---|---|---|
|区域|处理要点|参数参考|
|鼻梁|细线状高光，中部最强|画笔硬度80%，不透明度30%|
|眉骨凹陷处|需减弱高光强度|蒙版擦除50%区域|
|鼻尖|点状微光|3px画笔，15%不透明度|
解剖学依据：面部光影需符合额-鼻-嘴-下巴的立体结构，鼻梁高光宽度应控制在1-2mm。

### 3.18. 调整整体肤色﻿
- 调整整体肤色需先合并图层：隐藏白色背景后合并可见图层，生成独立肤色图层
- 色彩平衡工具的应用：通过调整红/黄色调实现白里透红效果，保留明度选项可维持亮度不变
- 色调选择依据：
    - 中东肤色：通常呈现暗黄特征
    - 欧美肤色：以冷白基调为主
    - 化妆品广告：优先采用冷色调增强唯美感
- 色彩调试注意事项：
    - 古铜色系需增加红黄比例
    - 冰清玉洁效果需添加洋红冷调
- 修图过度问题：案例中出现脸型失真现象，下巴轮廓修改过强导致人物特征丢失
- 后期处理步骤：
    - 盖印修图成果后隐藏底层
    - 新建填充层更换背景色调
    - 适用于化妆品海报的二次创作
