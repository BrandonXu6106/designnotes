> [!info] 置换命令
> - **命令定义**：用于对物体进行==形状改变==的滤镜==扭曲工具==
> 	- 与液化区别：同属形变工具，但置换更==专注于纹理贴合==
> - **工作原理**：通过==模拟纹理走向==实现视觉上的融合效果
> - **应用场景**：布料、岩石、风景等材质的纹理扭曲处理
> 	- **典型应用**：将平面图案贴合到褶皱布料表面
> - **局限性**：只能达到视觉上"还不错"的==近似==效果
> - **学习难度**：面板简单但==理论==知识点较==多==


## 1. 如何制作置换效果
>**前提准备**：需要==纹理对象==和==置换图形==两个元素
>![202607061803841.png|285](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607061803841.png)


### 1.1. 制作置换文件
#### 1.1.1. 纹理置换文件
- **纹理去色**`Ctrl+Shift+U`：==黑白对比==更明显
  ![202607061808479.png|274](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607061808479.png)
- **模糊细节**：颗粒感过强时需==降低细节==
	- **复制纹理**图层：复制纹理图层以调整对比度
	- **对比加强**：通过色阶(`ctrl+L`)增强明暗对比
	- **高斯模糊**：用于==减弱==图像==颗粒感==(2.5像素为示例值)
- **另存文件**：另存为==psd文件==，明确命名（如"布料光影"）


#### 1.1.2. 细节置换文件
- **复制**一份原文件
- **细节提取**：==高反差保留==
  ![202607061906368.png|321](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607061906368.png)
- **另存文件**：另存为==psd文件==，明确命名（如"布料细节"）


### 1.2. 置换图形
- **前提准备**：打开需要置换的==图形==，转化为==智能对象==
	- **目的**： ==可以双击修改==置换参数或原始图案
- **第一次执行置换命令**：滤镜→扭曲→置换→调整水平/垂直比例=10→确定右→选择==布料光影==PSD文件
  ![202607061818680.png|276](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607061818680.png)
	- **参数调整**：比例值需==反复调试==，方形图建议水平垂直比例相同
- **第二次执行置换命令**：滤镜→扭曲→置换→调整水平/垂直比例=10→确定右→选择==布料细节==PSD文件
	- **参数调整**：比例值需==反复调试==，方形图建议水平垂直比例相同
- **叠加模式**
	- 只显示原来未处理的==纹理图层==和置换后的==图形图层==
	- **修改模式**：==叠加模式==
	  ![202607061823681.png|269](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607061823681.png)
- **颜色优化**
	- 修改**色相明度**：==双击==智能对象，选区框选，`ctrl u`修改色相明度
	- **复制叠加**图层：`ctrl j`
	- **不透明度**：颜色过重时，调低点
	  ![202607061911956.png|286](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607061911956.png)

## 3. 置换命令参数讲解
- **水平比例**与**垂直比例**
	- **理解**：可以将比例==理解为通道==
		- ==水平==比例：控制==红色通道==
		- ==垂直==比例：控制==绿色通道==

## 4. 例题: 字体置换
**素材准备**：
![202607061902756.png|233](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607061902756.png)
### 4.1. 置换文件制作
- ==两个==**置换文件**
	- **纹理文件**制作：==高斯模糊+去色==
	- **颗粒细节文件**制作：==高反差保留==


### 4.2. 置换图形
- **执行两次置换**
	- 第一次**选纹理文件**
	- 第二次**选颗粒细节文件**
- **参数调整**：水平/垂直比例需==反复尝试==(建议5-10)，使得伸展适合
- **混合模式选择** ：`正片叠底`/ `叠加模式`


### 4.3. 岩石光影提取
- **光影提取方法**：双击图层，使用==混合颜色带==调整
	- `下一图层`：先拖动亮部滑块，再`alt`分块
	  ![202607061901858.png|305](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607061901858.png)


> [!TIPS] TIPS：
> - **位置锁定**：置换后图形不可大幅移动，否则会破坏纹理对应关系
> - **商业应用**：需多次置换+混合模式+颜色调整才能达到真实效果
> - **通道原理**：置换本质是依据通道灰度值进行像素位移(非必须掌握)


## 5. 知识小结

| 知识点     | 核心内容                                                                                        | 考试重点/易混淆点                       |
| ------- | ------------------------------------------------------------------------------------------- | ------------------------------- |
| 置换命令的作用 | 通过底层纹理的黑白关系（光影）控制上层图形的扭曲走向，模拟三维贴图效果                                                         | 置换是模拟真实纹理贴合，非100%精确，需结合图层混合模式调整 |
| 置换操作步骤  | 1. 准备置换纹理（需模糊处理+强化明暗对比）<br><br>2. 存为PSD文件<br><br>3. 对目标图形执行“滤镜-扭曲-置换”<br><br>4. 调整水平/垂直比例参数 | PSD文件格式为硬性要求；模糊程度需平衡细节保留与平滑度    |
| 参数原理    | - 水平比例：控制红色通道区域的扭曲强度<br><br>- 垂直比例：控制绿色通道区域的扭曲强度<br><br>- 蓝色通道无效                            | 通道对应关系需实验验证，实际应用需反复尝试参数         |
| 细节强化技巧  | 1. 通过高反差保留提取纹理细节<br><br>2. 二次置换增强真实感<br><br>3. 混合颜色带提取底层高光/暗部                               | 分层处理光影与细节（如：延时光影+延时纹理分开置换）      |
| 常见应用场景  | - 布料褶皱贴图<br><br>- 岩石/大理石纹理融合<br><br>- 风景类场景元素适配                                             | 图形与纹理比例匹配影响最终效果（方形图建议水平/垂直比例一致） |
| 易错点     | - 置换后移动图形会导致纹理错位<br><br>- 过度模糊丢失关键细节<br><br>- 忽略混合颜色带调整                                     | 置换对象必须为智能对象以便参数修改               |
