## 1. 模糊>>表面模糊
- **模糊特性**
    - ==边缘保留==：
        - 能==保持==明显颜色/明暗对比的==边缘轮廓==
        - 主要==对物体内部==或==外部区域==进行==模糊==
          ![202607042227833.png|198](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042227833.png)
- **参数控制**
	- **半径**：控制==模糊剧烈程度== 
	- **阈值**：控制模糊==作用==的色阶==范围==
- 与**高斯模糊**的**核心区别**：

> [!info] 高斯模糊vs表面模糊
> - **表面模糊**：==保留边缘==的==智能==模糊
> - **高斯模糊**：==完全==均匀的==整体模糊==



## 2. 模糊>>动感模糊⭐⭐⭐﻿
![202607042239730.png|361](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042239730.png)
- **功能定义**：通过==模拟物体运动轨迹==产生动态模糊效果，==常用于==表现==高速运动==或==光线拖尾==效果
- **参数控制**：
	- **角度**：控制模糊==方向==
	- **距离**：控制模糊==强度==


## 3. 模糊>>方框模糊﻿(不用)
- **基本原理**：在==动感模糊==基础上，==同时==进行==水平和垂直==方向的==模糊处理==，形成类似方框的模糊效果。
- **参数特点**：
    - **半径**：控制==模糊强度==
    - 无角度调节选项（区别于动感模糊）


## 4. 模糊>>高斯模糊﻿﻿⭐⭐⭐
- **核心特性**：
    - ==仅通过"半径"参数控制==整体模糊程度
    - ==不考虑画面颜色==分布和==比例==关系
- 实际应用：
    - 最==常用==
    - 适合==快速==创建整体模糊效果
    - 常用于==背景虚化==、==柔化边缘==等场景


## 5. 模糊>>模糊
- **效果特点**：产生==极其轻微==模糊效果，肉眼观察变化不明显


## 6. 模糊>>进一步模糊
- **效果特点**：效果==强度==是==模糊的两倍==
- **叠加特性**：在当前==模糊效果==基础上==叠加增强==
- **组合使用**：可交替使用==普通模糊和进一步模糊==实现==渐进式模糊==


## 7. 模糊>>径向模糊⭐⭐⭐
- **模糊方式**：
	- **旋转模糊**：围绕<u>圆心</u> ==旋转==
	  ![202607042255159.png|200](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042255159.png)
	- **缩放模糊**：==放射性==模糊
	  ![202607042259937.png|195](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042259937.png)
- **中心点控制**：可以手动拖动模糊中心点位置，决定模糊的起始位置
  ![202607042253658.gif|237](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042253658.gif)
- **品质选择**：模糊效果的==精细程度==
	- **草图**：效果粗糙但有==特殊颗粒感==
	- **好**：平衡效果与性能
	- **最好**：效果最==平滑精细==
- **应用**：==丁达尔光线==制作
	- 制作步骤：
		- 使用"选择→==色彩范围=="选取==高光区域==
		- ==复制==选区到新图层
		- 应用==缩放模糊==并调整中心点位置
		- 通过==复制==图层==增强==光线效果


## 8. 模糊>>平均模糊
- **效果说明**：==综合计算==所有像素的颜色和明暗信息，最终==生成单一纯色画面==
- **主要用途**：==材质纹理处理==（木纹/皮革等贴图场景）

### 8.1. 应用案例：材质纹理处理
- **典型问题**：
	- 多块材质==拼接==时出现明暗==不均==
	  ![202607042308371.png|216](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042308371.png)
	- ==单块==材质存在不自然的明暗过渡（如==中间亮四周暗==）
	  ![147](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042309206.png)
- **解决方案**：
	- **提取纹理**
		- ==复制==材质图层
		- 选中下一层，执行"==滤镜→其他→高反差保留=="（半径约5像素）
		  ![202607042311757.png|163](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042311757.png)
		- ==去色==（`Ctrl+Shift+U`）
	- **提取色彩**
		- ==选中==原材质图层
		- 执行"==滤镜→模糊→平均=="
		  ![202607042314110.png|177](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042314110.png)
	- **混合模式**
		- ==线性光==
		  ![202607042315473.png|215](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042315473.png)
	  - 接着**拼图**



## 9. 模糊>>特殊模糊﻿
- **功能特性**：==与表面模糊完全相同==，可视为表面模糊的==精细版==
- **智能识别**：毛孔、斑点==保持细节==，平滑区域（如额头）加强模糊
- **使用局限**：==仅==适用于==人物肤色==处理，商业设计其他场景很少使用


## 10. 模糊>>形状模糊(不用)
![202607042326584.png|206](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607042326584.png)
- **模糊原理**：通过==预设形状（==如动物、植物等图案）作为==模糊模板==
- **视觉效果**：==效果==与形状关联性==弱==，肉眼==难以分辨==差异
- **实用价值**：属于特殊效果滤镜，设计工作中基本==不会使用==


## 11. 模糊>>镜头模糊(不用) 
- **适用人群**: 主要面向==专业摄影师==使用，平面设计领域较少应用
- **核心功能**: ==模拟相机镜头==产生的==特殊模糊==效果，可调整光斑形状和光影效果
- **核心参数**：
    - 六边形亮度：影响光斑的发光强度
    - 阈值：控制光斑的显现范围
    - 旋转：调整光斑的角度变化
    - 半径：决定光斑的扩散大小
- **分布方式**

	- **平均分布**:
	    - 特点：均匀添加杂色，==不考虑画面明暗关系==
	    - 效果：在亮部和暗部都添加等量杂色
	- **高斯分布**:
	    - 特点：根据画面明暗关系==智能添加杂色==
	    - 效果：暗部杂色更丰富，亮部杂色较少
	- **选择建议**：需要自然效果时选择==高斯分布==


## 12. 模糊类型总结
- 常用模糊
	- **表面模糊/特殊模糊**：主要用于==人像磨皮==处理
	- ⭐⭐⭐**动感模糊/高斯模糊**：==光效制作==的核心工具，需重点掌握
	- ⭐⭐⭐**径向模糊**：兼具旋转和缩放功能，适合制作==光线==效果

- 不推荐模糊
	- **模糊/进一步模糊**：无参数控制，效果不可控
	- **形状模糊**：变化效果难以预测和调整
	- **平均模糊**：仅适用于色彩平均化处理，做纹理

- 摄影师使用模糊
	- **镜头模糊**：模拟相机景深和光斑效果


## 13. 知识小结

| 知识点      | 核心内容               | 应用场景           | 关键参数                  |
| -------- | ------------------ | -------------- | --------------------- |
| 表面模糊     | 保留边缘轮廓的同时模糊内部/外部区域 | 人物磨皮、保留边缘的局部模糊 | 半径(模糊程度)、阈值(色阶范围)     |
| 高斯模糊     | 整体均匀模糊，不考虑边缘差异     | 光效制作、整体柔化      | 半径(模糊强度)              |
| 动感模糊     | 产生方向性运动轨迹效果        | 速度感表现、光线轨迹     | 角度(方向)、距离(强度)         |
| 径向模糊     | 旋转/缩放两种模糊方式        | 放射光线、旋转效果      | 数量(强度)、模糊方法(旋转/缩放)、品质 |
| 平均模糊     | 计算画面色彩平均值生成单色      | 材质贴图统一色调       | 无参数(自动计算)             |
| 特殊模糊     | 智能识别该模糊的区域         | 精细磨皮处理         | 半径、阈值、品质              |
| 镜头模糊     | 模拟相机景深和光斑效果        | 摄影后期、艺术效果      | 光圈形状、镜面高光、焦距          |
| 形状模糊     | 基于预设形状进行模糊         | 特殊纹理效果         | 半径、形状库                |
| 模糊/进一步模糊 | 无参数傻瓜式模糊           | 快速轻微模糊         | 无参数                   |

| 对比维度 | 表面模糊    | 高斯模糊 | 动感模糊   | 镜像模糊    |
| ---- | ------- | ---- | ------ | ------- |
| 边缘处理 | 保留明显边缘  | 完全模糊 | 方向性模糊  | 中心点辐射   |
| 核心优势 | 选择性区域模糊 | 均匀平滑 | 运动轨迹表现 | 放射/旋转效果 |
| 典型应用 | 皮肤处理    | 光效柔化 | 速度线制作  | 丁达尔光线   |
