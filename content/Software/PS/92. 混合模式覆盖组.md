>- **基本认识**：一共==27种==混合模式，分为六个功能组
>- **掌握目标**：熟练掌握并使用其中的==12种==模式，能够满足工作需求
>- **应用原则**：实际设计中主要==依赖视觉感受==而非公式计算。

## 1. 基础概念
![202607072344113.png|341](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607072344113.png)
- **基色**：==下方图层==的原始颜色，作为混合的基础色。
- **混合色**：==上方图层==，用于==影响基色==的颜色，通过混合模式产生作用。
- **结果色**：基色与混合色通过特定==混合==模式计算后==产生的==第三种颜色效果。
- **混合模式本质**：两个图层之间进行色彩/明度/饱和度的==数学计算==方式。
- **现实调整逻辑**：实际设计中应通过==视觉调整==而非数学计算，因像素级==计算不现实==。


## 2. 混合模式﻿分组
>混合模式分组：分为覆盖组、去亮组、去暗组、对比组、差值组、色彩组，共六个组。

1. **覆盖组**：图层混合模式中的第一组，也被称为正常组。
2. **去亮组**：包含五个模式，主要功能是==去除==图像中的==亮部==。
3. **去暗组**：包含五个模式，主要功能是==去除==图像中的==暗部==。
4. **对比组**：包含七个模式，主要用于增强图像的对比度(==亮的更亮==、==暗的更暗==)。
5. **差值组**：包含四个模式，基于==颜色差值==进行计算。
6. **色彩组**：也称为颜色组，用于调整图像的==色彩属性==。


## 3. 覆盖组
### 3.1. 正常 
>- **正常模式**：也是一种混合模式，需配合不透明度参数使用。

![202607072344113.png|341](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607072344113.png)
- **基础公式**：结果色= <u>混合色×不透明度</u> + <u>基色色值×(1-不透明度) </u> 
	- `不透明度`：控制混合色对基色的==影响程度==，100%为完全影响。
		- `不透明度快捷键`：小键盘数字（1=10%，5=50%，0=100%，快速双击可输入两位数百分比）。
- **现实调整逻辑**：实际设计中应通过==视觉调整==而非数学计算，因像素级==计算不现实==。


### 3.2. 溶解
![202607081816852.png|343](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607081816852.png)
- **效果定义**：==针对==<u>透明像素点</u> ，产生破==碎像素点==效果，的特殊图层混合模式。
	- **效果特征**：产生==无规律==的==颗粒状==分布(==无公式==)，颗粒密度==与不透明度成正比==。
- **触发条件**：需存在==有透明像素点==的图形。
- **应用场景**：适合需要制作==颗粒质感==或==半透明散点==效果的设计需求。
