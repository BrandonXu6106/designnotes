| 快捷键   | 功能                            |
| ----- | ----------------------------- |
| ⌘ f   | 视图聚焦自适应                       |
| ⌘ n   | 新建空白流                         |
| ⌘ d   | 加载默认文生图工作流                    |
| ⌘ +   | 放大视图                          |
| ⌘ -   | 缩小视图                          |
| ⌘ ⏎   | 生图                            |
| ⌘ b   | 忽略节点<br>跳过当前节点功能, 但依然识别首位相连节点 |
| ⌘ m   | 关闭节点<br>关闭当前节点所有功能, 相当于把节点删除  |
| ⌘ ⇧ C | 复制节点与连线                       |
