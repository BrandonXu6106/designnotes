体验设计实践的区分维度：具体项目和场景(C端和B端)
- C端：一般**消费者**端的产品
- B端：面向**商业用户**的产品


## 1. 差异的来源
差异来源：产品性质

|           | C端产品                  | B端产品                   |
| --------- | --------------------- | ---------------------- |
| **使用目标**  | 生活娱乐                  | 工作需要                   |
| **使用动机**  | 个人需求                  | 内部要求                   |
| **盈利模式**  | 用户主动==使用==产品提供的==服务== | 工作强制要求，员工被动使用去==解决问题== |
| ⭐**体验权重** | 极高 (为了数据增长)           | 较低 (只为提高效率)            |
| **操作难度**  | 直接上手                  | 需要培训                   |
差异来源：用户群体

|          | B端用户 | C端用户 |
| -------- | ---- | ---- |
| **用户规模** | 庞大   | 极少   |
| **用户类型** | 庞杂   | 清晰   |
| **用户需求** | 模糊   | 具体   |
| **配合意愿** | 极低   | 极高   |

## 2. 差异的影响
**数据统计方法和指标**—用户规模的影响
- C端：有庞大的用户群体可以生产数据，==样本量大==使得数据的统计结果更==有质量==
- B端：用户数量极小且产生的==数据很分散==，无法作为有效的统计样本去收集数据

> [!summary] 
> C端数据统计方法、指标对B端==不适用==
> 


**操作的主导权**—用户类型的影响
C端：用户群体覆盖多种年龄段和类型，不同用户的偏好和行为有极大的==差异==
B端：用户群体的差异对使用产品影响很小，是==产品的形态决定==了用户应该如何进行操作
> [!summary] 
> C端：产品适配用户
> B端：用户适配产品


**功能的探索**—用户需求的影响
C端：用户除了底层需求外，其它需求难以琢磨，产品需要尝试不同的功能来==摸索==用户的==兴趣==
B端：用户使用产品，目标是用于解决工作问题，使用==目标清晰==，需要增加什么功能还是优化什么内容，==想法明确==
> [!summary] 
> C端：需求模糊，需要探索
> B端：需求清晰，目标清晰


**用户调研的方法**——配合意愿度的影响
C端：大多数用户==不愿意==配合团队做调查研究，愿意配合的用户往往就不是有效样本
B端：用户迫切希望B端产品能更好用更高效，==非常乐意配合==产品设计，探讨产品的优化点
> [!summary] 
> C端：用户规模更大，更依赖==数据分析==——物理距离的隔阂
> B端：用户规模极小，更依赖==直面沟通==——物理距离极小


**设计的聚焦点**
C端：更着眼于==整体(宏观)==——品牌化、设计原则、服务方式
B端：更着眼于==局部(具体)==——特定功能优化、特定流程优化、特定交互优化

**工具和方法的选择**
C端：体验设计的工具和方法==多数==围绕C端构建
B端：B端体验设计不能直接照搬，要建立==新的体系==——⭐==用户访谈==、用户测试、体验量化
> [!summary] 
> C端：方法极多、选择极多
> B端：特定方法、特定选择
