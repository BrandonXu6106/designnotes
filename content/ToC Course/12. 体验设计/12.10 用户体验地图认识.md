## 3. 地图结构
地图结构：==X轴==(一个阶段) + ==Y轴==(不同要素)，组合成的==表格==
![202607272032811.png|447](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202607272032811.png)
### 3.1. 阶段X轴
产品不同的使用阶段，不仅限于产品内的使用。
**看见**广告：看见外部投放广告
**下载**应用：到应用商店或官网下载
**启动注册**：打开应用完成注册并登录
开始**使用**：使用产品的主要服务功能
完成**付费**：完成商品购买或会员充值

### 3.2. 要素Y轴
在每个阶段中提取的不同纬度信息，进行更精确细致的整理。
**行为**：用户这个阶段会开展的==动作和实践==
**目标**：用户现阶段要实现的目标是什么
**触点**：用户该阶段会接触的==信息==和==操作对象==
**想法**：用户再该阶段产生的==心理活动和想法==
**情绪**：用户在该阶段的==情绪状态==类型
**问题**：用户在该阶段会产生的==疑问、阻力==
**机会**：该阶段还可以进行==优化的要点==

## 4. 应用流程
前期分析 → 创建视觉框架 → 内容填充 → 材料整理 → 输出结论

### 4.1. 前期分析
1. 开展的==原因和目标==
2. ==需要==输出的==结果==
3. 需要==研究==的==方式==
4. ⭐需要==研究==的==对象==
	- 用户==类型==+每个类型下的研究==人数==
5. ==时间==和节点==排期==


### 4.2. 创建视觉框架
**份数：**
- 一张地图：一个用户体验信息
- n个用户：n份体验地图文件


**Y轴纬度：**
可以按需修改，==无需照搬==

| 维度  | 阶段1 | 阶段1 | 阶段1 |
| --- | --- | --- | --- |
| 目标  |     |     |     |
| 行为  |     |     |     |
| 场地  |     |     |     |
| 用时  |     |     |     |
| 想法  |     |     |     |
| 机会  |     |     |     |


**模版**:
Figma社区模版——社区搜 "User Experience Map"

### 4.3. 内容填充
通过==可用测试==和==访谈==，完成对不同用户的体验地图信息==填充==

### 4.4. 材料整理
收集检查材料，并可以==合并==**同类用户**的==地图信息==

### 4.5. 结论输出
总结体验地图当中的==主要问题==和==机会点==，并给出项目进一步==优化==体验的==方案==建议

> [!tip] 
体验地图可以使用==调研==方法来完成，也可以通过==逻辑推导==的方式进行预判


## 5. 同理心地图vs体验地图
 
| 对比项      | 同理心地图                            | 用户地图                                 |
| -------- | -------------------------------- | ------------------------------------ |
| **研究对象** | 挖掘==内在心理==(情绪/想法/观点)             | 梳理==行为流程==(场景+单一任务)                  |
| **时间维度** | 无时序，静态                           | 强时间轴，阶段性，持续性                         |
| **地图结构** | - 经典四象限：说/做/想/感受<br>- 新增部分：痛点/需求 | - X轴：阶段<br>- Y轴：行为/目标/触点/想法/情绪/痛点/机会 |
| **使用阶段** | ==早期==用研：建立共情                    | ==多后期==梳理：需求落地，方案优化                  |

**场景：外卖点餐用户**
> [!example] 同理心地图
> - 用户**想什么**：担心餐凉、怕超时、担心分量不足
> - 用户**感受**：焦虑、纠结、选择困难
> - 用户**说**：“不知道哪家靠谱”
> - 用户**做**：反复翻看评价
> → **只刻画这个人的状态，不分先选店、下单、等待、收货流程**

> [!example] 用户体验地图
> 1. **阶段 1**：打开 APP→行为：浏览商家→情绪平淡，痛点：筛选麻烦
> 2. **阶段 2**：挑选菜品→行为：对比价格→情绪烦躁
> 3. **阶段 3**：提交订单→行为：填写地址
> 4. **阶段 4**：等待送餐→情绪焦虑
> 5. **阶段 5**：收到外卖→情绪满意 / 失望
> → **严格按照时间先后，走完完整任务流程，附带情绪曲线**
