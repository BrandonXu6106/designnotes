## 3. 用户调研的框架
==适用性最广泛==的用户**调研框架**：先有分析，了解用户，产生问题
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202606181824819.png)

### 3.1. 认识用户(用户画像)
而我们理解用戶的**第一步**首先是解决用户是谁的问题，即分析**用户画像**。通过建立用户画像来建立同理心（站他们角度思考），预判用户对产品的要求与反应。 (典型：车的用户定位)
**用户画像**分析的三种方法：
![202606181832693.png|540](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/202606181832693.png)

**数据分析**：对于新项目而言，用户量太少，==数据量不够==，数据分析就没有价值

**用户调研**：需要耗费==大量的精力和时间==。在**真实项目**中，只有分析的问题足够重要，==时间==充足，其它==条件==成熟的情况下==才会开展==专业的用户调研。

**主观构建**：对于**中小项目**来说，我们更多使用==经验和主观推导==来建立初级的用户画像，因为==条件所限无法==做出足够精确的统计或得到准确的答案，所以**项目前期的策略都是**==先“假想”==，然后上线产品测试==收集数据==，再做==纠正和迭代==。

**TIPS**：<u>产品没具体上线之前，画像的整理往往都是失效的</u> ，产品<u>先搭建起来能够面向市场进行“试错”</u> ，<u>才是最高效合理的做法</u> 。

### 3.2. 用户调查
除了构建用户画像，还可以通过其他方法

- **用户问题1**：用户关注目标城市的游玩目的地<u>检索顺序和方式</u> 
- **目标**：优化城市<u>主页</u> 的<u>设计和布局</u> 
- **调研方式**：
	1. 确定==3组==不同调研群体，每个群体==访谈==5人
	2. 确定访谈的主要==提问内容==，罗列相关==问题点==
	3. 确定进行访谈的==渠道==和==时间==，以及==记录方式==
	4. ==整理==访谈记录，==总结==用户的痛点和产品优化点


- **用户问题2**：用户预定酒店的<u>筛选习惯和权重</u> 
- **自标**：优化酒店模块的操作流程和展示效果
- **调研方式**：
	1. 无差别==问卷调研==，至少回收==100份以上==问卷
	2. 确定问卷的主要==内容==和具体==问题==制作问卷
	3. 确定问卷的==投放形式==和==渠道==，以及回收点
	4. ==整理==问卷反馈，==总结==用户的购买倾向和习惯
 

⭐⭐⭐**TIPS**：<u>重要的不是怎么做调研，而是怎么提出问题，</u> 实际的工作场景中，往往更==关注投入和产出比==
>用户调研需要耗费大量的精力，==项目即使没有用研也可以正常推进==
