## 1. Loading 是什么

加载指示器：转圈动画、加载文字「加载中…」。

## 2. 锁定交互是什么
锁定交互 = **加载等待的时候，不让用户点击任何操作按钮**

## 3. 完整例子（订单结算页）

❌ 糟糕做法（没处理） 页面打开 → 直接亮出【提交订单】亮色按钮 网络慢，2 秒后拿到数据：余额不足 → 按钮突然变灰 用户刚准备点，按钮瞬间失效，非常迷惑。

✅ Loading + 锁定交互方案怎么做
1. 页面刚加载，弹出全屏 / 区域转圈 Loading；
2. **此时锁定所有按钮，用户点了没有任何反应**；
3. 等后台全部数据拿到；
4. 关掉 Loading，再展示真实价格、真实可用 / 置灰按钮。


## 4. 优缺点
✅ 优点：实现简单，开发成本低 
❌ 缺点：整个区域一片等待，用户看不到页面结构，耐心差的人容易退出 
适用：弹窗、简单页面、弹窗支付、次要浮层
