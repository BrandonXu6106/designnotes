动效的学习要求：只需要使用**1个月**的时间就能掌握

>**⭐Protopie精通 + AE入门**




| 软件类型                      | 软件                       | 使用场景                                             | 优缺点                                                  |
| ------------------------- | ------------------------ | ------------------------------------------------ | ---------------------------------------------------- |
| **交互原型软件**                | Axure                    | - 产品原型、交互原型、产品文档<br>- 实现教为==复杂==的==数据==交互和控制     | 操作==复杂==，制作==效率低==下                                  |
|                           | Modao(墨刀)                | 国产、类Axure原型工具但                                   | 只能实现更==基础==、简单的交互效果                                  |
|                           | Figma、JS Design          | 添加连线和交互方式<br>                                    | ==过于简单==，没办法制作复杂效果                                   |
|                           | PPT                      | 关键帧动画效果                                          | PPT制作==简单演示==                                        |
| **可交互动效软件**<br>(专业交互、自定义) | ⭐⭐⭐Protopie              | 用途：界面动效、车机交互 (==流程化==操作)                         | **优点**：==最完善==的动效软件<br>**缺点**：==贵！==                 |
|                           | Principle                | 用途：==单个交互==事件动效                                  | **优点**：==最轻量化简单==的动效软件<br>**缺点**：==更新==少，只能==MAC==使用 |
|                           | Flinto、Origami、Framer... | —                                                | —                                                    |
| **动画特效软件**<br>(专业动画)      | Adobe After Effects      | 影视特效、游戏特效<br>制作非关键帧动效<br><br>只有无法用动效软件制作的动效才使用AE | 优点：最==主流==的动画特效软件<br>缺点：操作==繁琐==、==效率==低下、==无法交互==   |
|                           | Motion                   |                                                  |                                                      |
