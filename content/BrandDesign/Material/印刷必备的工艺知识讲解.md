## 1. 印刷工艺及细分品类
![20261011094641448.png|465](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011094641448.png)

### 1.1. 击凸/压凹工艺
1. 特性

利用凸模板 ( 阳模板 ) 施压，纸面局部凸起形成浮雕图案即为击凸；

依靠凹模板 ( 阴模板 ) 施压，纸面局部下陷形成凹陷浮雕即为压凹；

总结：无需油墨，纯物理压制成型，成品凹凸立体、触感鲜明。

2. 常见用途

名片、精装画册封面、礼盒、特种吊牌、高端贺卡、艺术纸品等工艺装饰。

3. 适配用纸

加厚双胶纸、特种艺术纸、白卡、牛卡等挺度充足的厚纸张。


压纹
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011094918882.png)

1. 特性

借助带凹凸纹路模具，在温压作用下让纸张形变形成肌理纹路，分平板压纹、辊筒压纹两类。

总结：纸面生成规则肌理，浮雕质感突出，提升纸品艺术质感。

2. 常见用途

礼盒面纸、精装封面、艺术画册、高档手提袋、特种纸品。

3. 适配用纸

厚卡纸、特种艺术纸、牛卡、高克重哑粉纸。

局部UV
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011094931502.png)

1. 特性

分为满版 UV 与局部 UV，局部 UV 是在印刷局部涂布光油，经紫外光固化，局部形成高亮透亮效果。

总结：局部区域高光亮面，耐磨通透，和普通印刷面形成光泽反差。

2. 常见用途

包装盒、画册封面、名片、高档宣传单、文创纸品。

3. 常用搭配

铜版纸、哑粉纸、白卡、特种印刷卡纸。

逆向UV
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011094941358.png)

1. 特性

面油、底油两种油墨叠印后 UV 固化，同一版面同时呈现镜面亮光与磨砂哑光两种反差光泽，套印精度高。

总结：一印双光泽，亮哑对比强烈，油墨耐晒防潮，保护性更强。

2. 常见用途

高端药盒、精品礼盒、精装画册、轻奢产品外包装。

3. 适配用纸

高克重铜版、哑粉、白卡纸。

逆向磨砂
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095007281.png)

1. 工艺说明

逆向磨砂工艺是近一两年出现的一种新型印刷工艺 ; 该工艺是将印品按照正常的色序印刷后，在油墨彻底干燥或固化基础上，

采用胶印连线 ( 或脱机 ) 方式在不需要突出高亮度的局部区域印上一层特种底油，待底油完全干燥后再以满版方式在整个印刷

品表面涂布 UV 上光油。这样在 UV 上光油和底油接触的区域发生内聚反应，形成小颗粒状的墨膜，构成哑光或磨砂毛面 ; 而在

未印刷底油的 UV 上光区域形成高光泽的镜面。最终，印品表面形成局部高光泽和局部磨砂低光泽区域。

2. 特点

具有磨砂效果，能使印品的印制效果更好、更精美，印刷质量更上一层楼。

3. 适配用纸

涂布白卡、加厚哑粉纸、特种覆膜卡纸。

覆膜
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095027081.png)

1. 特性

将塑料薄膜经加温加压贴合纸面，分为亮光膜、哑光膜、水晶膜；亮膜透亮高光泽，哑膜柔和不反光。

总结：表层覆塑防水防刮，提亮或柔化纸面，延长印刷品使用寿命。

2. 常见用途

宣传单、画册、彩盒、手提袋、名片、各类纸质包装。

3. 常用薄膜

光膜、哑膜、触感膜、防刮水晶膜。

刷边
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095041422.png)

1. 特性

针对厚纸侧边裁切位上色装饰，分为滚金边、喷色、侧边丝印三种工艺，在纸堆切面做色彩修饰。

总结：书本 / 名片侧边上色精致，提升整体档次与精致度。

2. 常见用途

厚本精装书、加厚名片、台历、精装画册、收藏卡册。

3. 工艺分类

滚金边、侧边喷色、侧边丝网印。

压点线
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095109375.png)

1. 特性

依靠机械压力在纸面压出隐形纹路，沿压线可轻松整齐撕离，不撕裂纸张。

总结：预留撕拉位，提升纸品实用性，兼顾规整美观。

2. 常见用途

优惠券、门票、撕拉式画册、产品说明书、便撕卡。

3. 适配用纸

铜版纸、双胶纸、白卡纸等常规印刷用纸。

烫金 / 烫银
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095121311.png)

1. 特性

高温加压把电化铝箔热转印至纸面，分热烫、冷烫工艺，成品自带金属镜面光泽。

总结：金属质感醒目耐磨，图案精致，提升纸品奢华质感。

2. 常见用途

礼盒 LOGO、名片、画册标题、商标、高端封皮、吊牌。

3. 常用箔材

烫金箔、烫银箔、镭射彩箔、哑金哑银箔。

镭射压印
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095135687.png)

1. 特性

印面先涂布 UV 光油，贴合镭射转移膜后经 UV 紫外固化，剥离膜体后镭射纹理转印至纸品表面。

总结：表面呈现炫彩镭射幻彩光泽，环保可回收，自带防伪效果。

2. 常见用途

彩妆礼盒、护肤品包装盒、高档烟酒外包装、轻奢品牌精装盒。

3. 适配用纸

高克重白卡纸、覆膜铜版卡纸、特种镀铝卡纸。

模切
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095146478.png)

1. 特性

定制专用钢刀模具，借助压力裁切，将纸张裁切成异形轮廓与预制压痕。

总结：打破方正版型，实现异形、开窗、弧线造型，包装立体成型。

2. 常见用途

异形礼品盒、开窗彩盒、异形吊牌、异型卡片、手提袋成型。

3. 适配用纸

白卡、牛卡、铜版卡纸、各类厚型包装用纸。

发泡
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095156706.png)

1. 特性

网印专用微球发泡油墨，印后加温受热，图文受热隆起形成蓬松凸起肌理。

总结：无凹凸压模，靠油墨受热起鼓，纸面柔软立体、颗粒质感。

2. 常见用途

文创封面、贺卡、艺术画册、品牌 LOGO 凸起装饰、儿童绘本。

3. 适配用纸

双胶纸、艺术特种纸、加厚白卡纸。

植绒
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095212547.png)

1. 特性

印刷区域涂刷粘合剂，短绒毛纤维垂直附着纸面，成品类似绒布触感。

总结：绒面立体饱满，手感软糯，色彩鲜亮耐磨，防潮不易掉绒。

2. 常见用途

高档贺卡、礼盒局部装饰、艺术画册封面、文创吊牌。

3. 适配用纸

厚白卡、特种艺术卡纸、覆膜哑粉纸。

丝网印刷
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095234378.png)

1. 特性

油墨透过丝网网孔漏印在承印物，墨层厚实，可适配平面、异形材质，手工 / 机印均可。

总结：墨层饱满厚重，附着力强耐日晒，适用特种油墨与特殊材质印刷。

2. 常见用途

包装盒大面积实底印刷、文创纸品、皮革纸品、特殊材质卡片。

3. 适配材质

各类卡纸、牛皮纸、PVC、皮革、特种艺术基材。

四色印刷
![](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095247350.png)

依托 C 青、M 品红、Y 黄、K 黑四色网点叠印，依靠网点大小混合还原全彩渐变画面。

总结：全彩画面通用工艺，色彩层次丰富，画册彩页主流印刷方式。

2. 常见用途

画册、海报、宣传单、书刊彩页、彩盒、产品手册。

3. 适配用纸

铜版纸、哑粉纸、双胶纸、白卡纸等常规印刷用纸。



## 2. 细分品类(基础印刷、印后工艺、工艺搭配及选材定义)
### 2.1. 印后深加工工艺汇总（常用表面工艺，封面装帧标配）

通用备注：所有印后装饰工艺，需在基础四色印刷工序完成后再加工，特殊工艺排版时需预留对位安全边距

1. 击凸 / 压凹：无油墨物理压制成型，纸面形成浮雕凹凸纹理；适配≥250g 厚卡纸；多用于封面 LOGO、装饰纹样立体塑形

2. 局部 UV：局部区域涂布 UV 光油，经紫外光线固化，局部形成高亮通透效果；全品类印刷用纸通用；封面图案提亮、重点

文字突出

3. 逆向 UV / 逆向磨砂：底油和面油分层叠印后 UV 固化，同一版面同时呈现亮光镜面与哑光磨砂两种反差质感；157g 及以

上涂布纸；高端礼盒、精装画册封面

4. 覆膜（光膜 / 哑膜）：纸面热压贴合塑料薄膜，隔绝水汽、防刮蹭；全品类印刷用纸通用；宣传单、彩盒、手提袋整体纸面防护

5. 烫金 / 烫银（热烫 + 冷烫）：高温 / 冷压将电化铝箔转印至纸面，成品自带金属镜面光泽；白卡、覆膜纸、特种艺术纸；

LOGO、标题文字、边角装饰

6. 压纹：带凹凸纹路模具在温压作用下，让纸张形变生成肌理；厚卡纸、艺术纸；礼盒面纸、精装书籍封皮

7. 过油（亮光 / 哑光）：整版纸面涂布透明清漆，防止印刷油墨蹭脏、提升纸面防护；双胶纸、薄款铜版纸为主；书刊内页、平装

画册整面防护

8. 刷边：厚纸书本裁切侧边做上色、烫金修饰；≥300g 合订厚纸；加厚名片、精装书本、精品台历侧边美化

9. 模切：定制钢制刀模，借助压力裁切出异形轮廓；全品类卡纸；异形彩盒、开窗包装盒、异型吊牌

10. 发泡 / 植绒：发泡油墨受热隆起成型；植绒依靠粘合剂固定短绒毛；双胶纸、艺术纸；艺术贺卡、文创封面局部肌理装饰


### 2.2. 工艺选配逻辑 & 厚度 / 尺寸参考

1. 工艺选配核心逻辑

成品工艺组合 = 基础主体印刷工艺 + 按需选配印后装饰工艺

备注：满版大面积特种工艺（满版 UV、整面植绒）对纸张挺度要求更高，优先选用高克重加厚纸张

常用纸张适配克重参考
![20261011095344659.png|364](https://int-1330323257.cos.ap-guangzhou.myqcloud.com//obsidian/pic/20261011095344659.png)

2. 搭配选型示例（画册封面：四色印刷 + 局部 UV + 哑膜）

成品封面尺寸 210×285mm，选用 300g 白卡纸

用纸选型：封面 300g 白卡，满足覆膜、UV、烫金多工艺叠加条件

工艺搭配逻辑：四色完成基础画面→整面哑膜防护→局部 UV 提亮 LOGO，由基础到装饰分步加工

适用场景：企业精装画册、产品手册封面标配方案

3. 快速选型口诀

薄页平装画册（157g 铜版）：优选胶印 + 哑光过油，轻薄防蹭脏

高档礼盒封面（300g 白卡）：四色 + 烫金 + 局部 UV + 哑膜，层次感最优

牛皮纸手提袋：凸版柔印 + 单面覆膜，适配牛皮纸粗犷质感

4. 工艺排版预留余量（设计排版必备）

烫金、击凸、UV 等精细工艺：图案距离成品裁边≥2mm，避免裁切时破坏工艺图案

满版大面积印后工艺：图案整体向内缩进成品 3mm，规避边缘套印错位

5. 成套选型实例（精装画册全工艺搭配）

成品尺寸 210×285mm，封面 300g 白卡，内页 157g 哑粉

内页选型：157g 哑粉四色胶印 + 哑光过油，保障内页翻阅不蹭墨

封面选型：300g 白卡，四色打底 + 哑膜整覆 + LOGO 局部 UV，兼顾防护与装饰

装订适配：内页胶装，封面加厚卡纸适配各类后道工艺
